概要

How to @openclaw on VPS safely: from fresh Ubuntu VPS → hardened private AI server in 30 min

---

まとめ

**新規Ubuntu VPSから30分でセキュアなOpenClawサーバーを構築する手順。**

Step 1: SSHロックダウン

sudo nano /etc/ssh/sshd_config
# 以下を明示的に設定：
PasswordAuthentication no
PermitRootLogin no
sudo sshd -t && sudo systemctl restart sshd

重要ポイント：

  • **鍵認証のみ** — パスワードログイン禁止
  • **rootログイン禁止** — 一般ユーザーでログイン
  • **設定テスト** — `sshd -t`で構文チェックしてから再起動

追加のセキュリティ対策（推奨）：

1. **ファイアウォール** — ufw/iptablesで必要なポートのみ開放

2. **Fail2ban** — ブルートフォース攻撃対策

3. **定期的なアップデート** — `unattended-upgrades`設定

4. **OpenClaw認証** — API認証を有効化

なぜ重要か：

  • fmdz警告への具体的な回答
  • 30分で完了 — 言い訳にならない
  • OpenClawを安全に運用するための必須手順
