概要

Clawdbot（現Moltbot）を使った自動化事例64個のまとめ。メール処理から記事生成、スケジュール管理まで幅広い自動化を紹介。

---

自動化リスト

📧 メール関連

  • 10分ごとにメールボックスを自動チェック
  • 新着メールの要約を自動生成
  • 返信が必要なメールを自動判定
  • 返信下書きを自動生成
  • 下書きをDiscordに投稿して承認待ち
  • 「OK」と返信するだけでメール送信
  • 迷惑メール・不要メールの自動フィルタリング
  • 処理済みメールの重複チェック

📅 カレンダー・スケジュール

  • 毎朝9時に今日の予定を自動通知
  • Googleカレンダーから予定を自動取得
  • タスク提案を過去の作業履歴から自動生成
  • 予定の作成をDiscordから指示するだけで完了
  • 予定にZoomリンクを自動追加
  • 色指定してカレンダーに登録

🔍 リサーチ・情報収集

  • 毎朝8時に海外AIニュースを自動配信
  • 週1で補助金情報を自動リサーチ
  • 競合分析を自動実行
  • 市場調査レポートを自動生成
  • ウェブ記事の要約を自動生成
  • ファクトチェックを自動実行

✍️ コンテンツ生成

  • 音声ファイル→文字起こし→ブログ記事を自動生成
  • メモ→Xポストを自動生成
  • Xポスト→Typefullyに下書きを自動保存
  • ブログ記事→図解画像を自動生成
  • ブログ記事→PowerPointスライドを自動生成
  • ポッドキャストのアイディアを自動提案
  • リードマグネット（無料PDF）を自動生成

📝 振り返り・記録

  • 毎晩21時に振り返りプロンプトを自動投稿
  • 週次振り返りレポートを自動作成
  • 会話ログをObsidianに自動保存
  • 作業履歴を自動記録
  • 学び・決定事項を長期メモリに自動蓄積

⚙️ タスク管理・ワークフロー

  • 10時と14時に自動でタスクを実行
  • 登録済みタスクから自動で作業開始
  • リサーチ結果を自動でファイル保存
  • 下書きを_pending/フォルダに自動保存
  • 作業完了をDiscordに自動通知
  • 「承認」と返信するだけで正式フォルダに移動
  • note記事をObsidianに自動アーカイブ
  • ドラフトと投稿版の差分を自動分析
  • 改善パターンを自動学習・蓄積
  • ファイルをGoogle Driveに自動保存
  • フォルダ構成に従って自動整理

🔗 連携サービス

  • Discord → 全ての通知ハブとして機能
  • Googleカレンダー → 予定の読み書き
  • Google Drive → Obsidian Vaultと同期
  • Gmail → IMAP経由でメール監視
  • Typefully API → Xポスト下書き保存
  • Groq API → 音声文字起こし

📱 マルチチャネル対応

  • Telegramで音声指示
  • LINE経由でAIに仕事依頼
  • LINEで重要タスク通知

💬 自然言語インターフェース

  • Discordから自然言語で指示するだけで実行
  • 音声メッセージを送ると自動で文字起こし
  • 「〇〇して」と言うだけでタスク実行
  • 確認が必要な作業は必ず聞いてくる
  • 時間指定の約束は自動でリマインダー登録

🖥️ 運用・コスト

  • 24時間365日VPSで稼働
  • 複数のAIエージェントを並列実行
  • 人間は確認してOK出すだけ
  • 秘書・リサーチャー・ライターを1人で代替
  • 月額数百円のVPS代だけで運用
  • Google AI UltraでOpus 4.5ほぼ使い放題
  • デザイン関連タスクはGemini 3 Proに切り替え
