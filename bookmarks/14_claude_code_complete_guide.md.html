概要

全10パート・約50チャプターでClaude Codeの全機能を網羅した完全リファレンス。「知りたいときに、すぐ引ける」設計。

---

こんな方におすすめ

  • Claude Codeを基礎からしっかり学びたい
  • インストールしたけど、何ができるかわかっていない
  • 「あの機能どうやるんだっけ？」と毎回検索している
  • カスタムコマンドやHooksで自分だけのワークフローを作りたい
  • チーム開発でCLAUDE.mdの設計に悩んでいる

---

構成

| パート | 内容 |

|--------|------|

| Part 0 | **Claude Codeとは** - 概要・他ツール比較・料金・モデル選択 |

| Part 1 | **インストール** - Mac/Windows・ログイン・パーミッション最適化 |

| Part 2 | **基本操作** - 起動・コマンド・拡張思考・モデル切替 |

| Part 3 | **セッション管理** - コンテキスト・巻き戻し・スクリーンショット活用 |

| Part 4 | **CLAUDE.md活用** - @記法・階層設計・モジュール化 |

| Part 5 | **カスタムコマンド** - YAML・引数・複数引数 |

| Part 6 | **サブエージェント** - 並列処理・カスタム定義 |

| Part 7 | **Hooks** - 全イベント解説・終了コード制御・環境変数 |

| Part 8 | **MCP** - 外部ツール連携・セットアップ |

| Part 9 | **Web版とヘッドレス運用** |

| Part 10 | **Skills** - 動的知識読み込み・SKILL.md作成 |
