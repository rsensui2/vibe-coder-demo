Claude code使ったら完全自動で3万稼げてた件。

6つのAIエージェント体制：

1. リサーチャー：YouTubeやXから最新ネタを自動収集

2. アナリスト：投稿パフォーマンスを分析してライターへフィードバック

3. ライター：15種類以上の投稿パターン＋265件のバズ投稿データベースで生成

4. ポスター：Threads APIで自動投稿実行

5. フェッチャー：閲覧数・いいねデータを自動取得

6. スーパーバイザー：全体の監視・異常検知

ライターの採点基準（10項目×10点満点）、平均7.0未満は再生成。過去100件との類似度チェックも実施。
