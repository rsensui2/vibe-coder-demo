概要

GitHubが公開した仕様駆動開発を実践するツールキット"Spec Kit" 非常に使いやすくて良い。

---

まとめ

GitHubが公開した仕様駆動開発ツールキット。

**インストール:**

uvx --from git+https://github.com/github/spec-kit.git specify init <PROJECT_NAME>

**対応ツール:**

  • Claude Code
  • Gemini CLI
  • Codex

仕様を先に定義してから開発を進める「仕様駆動開発」をサポート。AIコーディングツールと組み合わせることで、より正確な実装が可能に。
