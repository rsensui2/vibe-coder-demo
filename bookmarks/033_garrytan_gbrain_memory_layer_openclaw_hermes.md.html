概要

もし OpenClaw や Hermes Agent に、10,000 以上ある Markdown ファイルすべてを完璧に想起できる能力を持たせたいなら、GBrain が役に立つ。

これはまさに、私自身の OpenClaw / Hermes Agent の構成そのもの。MIT ライセンスのオープンソースです。あなたの mini-AGI 構築の助けになればうれしい。

https://t.co/yFpFU4pn5b

---

まとめ

Garry Tan が公開した MIT ライセンス OSS `gbrain`。OpenClaw / Hermes 向けの長期記憶レイヤーで、Markdown 知識ベースを横断検索できる。

記事詳細

10,000 以上の Markdown ファイルを対象に、検索、エンティティ整理、取り込み、統合を行う設計。PGLite でローカル起動できるのがかなり強い。

活用ポイント

  • 生成AI / エージェント運用の実務ヒントとして保存価値が高い
  • Vibe Coding やプロダクト開発の教材ネタ、共有ネタに転用しやすい
  • 今後のスライド化、要約展開の一次ソースとして使える
