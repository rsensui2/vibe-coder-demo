概要

Claude Codeに新機能「Auto Mode」が追加。許可ボタンを押すのがめんどくさすぎる問題を解消する「ちょうどいい中間」の選択肢。

Auto Modeとは？

Claude自身がAI判断で「この操作は許可していいかどうかを決める」モード。全部自動承認するわけじゃない。

  • **プロジェクト内のファイル読み書き** → 安全と判断して自動承認
  • **外部ネットワークへのアクセスやシステムに影響するコマンド** → 危険と判断して確認を出す

人間が毎回「Yes / No」を押す代わりに、Claudeが代わりに判断してくれる仕組み。

注意点

  • AI判断にトークンを使うのでコストが少し増える
  • 判断が完璧とは限らない。Anthropic公式も「隔離環境での使用を推奨」としている
  • あくまでリサーチプレビュー（研究段階のお試し版）

起動方法

ターミナルから：

claude --enable-auto-mode
# または
claude --permission-mode auto

⚠️ VS Code拡張機能でClaude Codeを使っている場合はAuto Modeは使えない（2026年3月時点）

3つのモードの違い

| モード | 動作 | 安全度 |

|--------|------|--------|

| Auto-Accept Mode (acceptEdits) | ファイル編集だけ自動。コマンドは毎回確認 | 最も安全 |

| **【NEW】Auto Mode** | AIが判断して、安全そうなら自動、危なそうなら確認 | 中間 |

| Dangerously Skip Permissions | 全部自動。何も確認しない | 最も危険（隔離環境専用） |

まとめ

「全部ノーチェック（Dangerously Skip）は怖いけど、毎回確認もめんどくさい」だった人にとって、ちょうどいい選択肢がやっと来た感じ。
