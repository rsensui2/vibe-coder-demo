まとめ

**GitHubが公開した仕様駆動開発（Spec-Driven Development）のツールキット。**

概要：

  • **ライセンス:** MIT
  • **対応ツール:** GitHub Copilot / Claude Code / Gemini CLI
  • **対応OS:** Linux / macOS / WSL2

ワークフロー：

1. `/specify` — 仕様を作成

2. `/plan` — 詳細な技術スタックについて計画

3. `/tasks` — タスクの作成、実装指示

仕様駆動開発とは：

  • コードを書く前に仕様を明確化
  • AIに仕様を理解させてから実装
  • 手戻りを減らし品質を向上

活用シーン：

  • 新規プロジェクト開始時
  • 大規模な機能追加
  • チーム開発での認識合わせ

インストール：

uvx --from git+https://github.com/github/spec-kit.git specify init <PROJECT_NAME>
