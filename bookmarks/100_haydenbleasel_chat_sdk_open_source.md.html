要約

複数のチャットプラットフォーム向けボットをまとめて開発できる統合 TypeScript SDK, Chat SDK がオープンソース化された。Slack, Microsoft Teams, Google Chat, Discord などを横断して扱えるのが特徴で、現在はパブリックベータ。

本文

Today we're open sourcing the new Chat SDK, a unified TypeScript SDK for building chat bots across Slack, Microsoft Teams, Google Chat, Discord, and more. Now in public beta.

▲ ~/ npm i chat

Let's see how it works ↓

要約（日本語）

新しい *Chat SDK* をオープンソース公開。Slack、Microsoft Teams、Google Chat、Discord など複数のチャットプラットフォームを横断してボットを構築できる統合 TypeScript SDK。現在パブリックベータとして公開中。

`npm i chat` でインストール可能。
