まとめ

メルカリAI Security Teamの発表資料。Claude Codeを社内展開する際に、人間確認の強制、危険コマンドの追加確認、環境変数やsudoの制限、sandbox適用、社内ポリシー注入までを5つの対策として整理している。さらに、MDMで一律配布するとエンジニアと非エンジニアの両方を満たしにくいので、配布設定を役割別に分ける設計が肝という話。
