まとめ

個人開発で課金ページやオンボーディングのUXを改善する実践的な手法。abtest.designというA/Bテスト事例集サイトから、成功事例のAsIs（現状）とToBe（あるべき姿）をClaude Codeに言語化させ、Skillsとして保存→ページ作り込みに活用するワークフロー。

**活用ポイント:**

  • Claude Code SkillsにUXパターンを蓄積して再利用可能にする発想が秀逸
  • Vibe Codingの実践例として、非エンジニアでも応用可能
  • abtest.designはBlinkist、Uber、Duolingo等の実際のA/Bテスト結果を集めたサイト

記事詳細（abtest.design）

A/Bテスト事例集サイト。Blinkist（+23%トライアル登録）、Uber（ライド数2桁増）、Duolingo（+40%ストリーク継続）、Headspace（+10%無料トライアルCV）等、有名アプリの具体的なA/Bテスト結果と改善パターンを40件以上掲載。課金ページ、オンボーディング、CTA最適化など、コンバージョン改善に直結するノウハウの宝庫。
