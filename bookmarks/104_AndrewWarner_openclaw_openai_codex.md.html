X Article: OpenClawでOpenAI Codex（GPT-5.3 Codex）を接続・使用する方法

---

まとめ

OpenClawがマルチプロバイダー対応していることを示すX Article。Anthropic以外のモデル（OpenAI Codex）もOpenClaw経由で使えることを解説。BM 6,715は高い注目度。OpenClawユーザーにとってモデル選択肢の広がりを示す実用的な内容。

セットアップコマンド

# OpenAI Codexをオンボード
openclaw onboard --auth-choice openai-codex

# モデルを設定
openclaw models set openai-codex/gpt-5.3-codex

# 状態確認
openclaw models status --plain
