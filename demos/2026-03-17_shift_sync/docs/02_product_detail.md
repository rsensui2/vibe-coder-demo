# ShiftSync プロダクト詳細

## 主要機能

### 1. 相性スコア分析エンジン
スタッフ間の相性を0〜100点でスコアリング。
- 性格タイプ（16パターンのMBTI風分類）
- 過去のトラブル履歴
- コミュニケーションスタイル
- 業務上の相互補完性

ヒートマップUIでチームの人間関係を一目で把握。赤いペアは「要注意」、緑は「理想的な組み合わせ」として自動分類。

### 2. AIシフト自動生成
入力情報:
- 各スタッフの希望シフト・NG日
- 必要人員数（曜日・時間帯別）
- 相性スコア閾値設定
- スキル要件（資格・経験年数）

生成アルゴリズム: 制約充足問題（CSP）＋機械学習の組み合わせ。相性・公平性・スキルカバレッジを多目的最適化。

### 3. リアルタイム調整機能
生成されたシフトをドラッグ&ドロップで微調整可能。調整するたびに「この変更は相性スコアを-12点低下させます」とリアルタイム警告。

### 4. 離職リスク予測（Proプラン以上）
相性の悪いペアが長期間同じシフトに入り続けると離職リスクスコアが上昇。事前アラートで人事担当者に通知。

## 技術スタック
- フロントエンド: React + TypeScript
- バックエンド: Python（FastAPI）
- AIエンジン: 社内開発の相性分析モデル（LLM + 推薦システム）
- DB: PostgreSQL + Redis（シフト最適化キャッシュ）

## セキュリティ
- ISO27001準拠
- 個人情報の暗号化（AES-256）
- SOC2 Type II取得予定（2026年末）
