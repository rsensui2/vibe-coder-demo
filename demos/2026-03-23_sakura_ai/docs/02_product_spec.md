# プロダクト仕様書 - SakuraAI

## 機能一覧

### 1. スタイル診断（Sakura Style AI）
ユーザーの花見スタイルをAIが診断し、パーソナライズされたスポットを提案する。

**診断フロー:**
1. 「誰と行く？」→ ソロ/カップル/ファミリー/友達グループ/職場
2. 「どんな花見がしたい？」→ 映えを楽しむ/まったり/宴会/運動/ペット連れ
3. 「こだわりは？」→ 穴場希望/アクセス重視/食事充実/ライトアップ希望
4. AIが全国スポットから最適な3候補を提示

### 2. 今日行くならスコア（Today Score）
3指標をAIが統合してスポットごとの「今日の推奨スコア」を算出。

| 指標 | データソース | 重み |
|------|------------|------|
| 開花率 | 気象庁API + 独自センサー | 40% |
| 混雑度 | 人流データAPI | 35% |
| 天気 | 天気予報API | 25% |

**スコア表示:** ★1〜5で直感的に判断可能

### 3. 推しシーンで探す（Scene Search）
雰囲気カテゴリから逆引きでスポットを検索。

**カテゴリ一覧:**
- 🌅 早朝の誰もいない桜
- 🌙 夜桜・ライトアップ
- 🏯 お城・歴史的建造物と桜
- 🌊 川沿い・水辺の桜
- 🐕 ペット同伴OK
- 👶 子連れ・ベビーカーOK
- 📸 映えスポット
- 🍺 お酒・BBQOKエリア

### 4. 花見計画まるごとAI（Full Plan）
計画立案から当日リマインドまでワンストップサポート。

**提供機能:**
- 最適日程提案（開花予測×スケジュール）
- グループ人数に合わせた持ち物チェックリスト
- お弁当・おすすめグルメ提案
- 前日・当日朝のリマインド通知
- 雨天時の代替案自動提示

## 技術スタック（想定）
- Frontend: React Native（iOS/Android）
- Backend: Python (FastAPI)
- AI: GPT-4o / Claude 3.5 Sonnet（ハイブリッド）
- データ: 気象庁API・Google Maps・独自クローリング
- インフラ: AWS / Vercel

## 非機能要件
- レスポンスタイム：2秒以内
- 可用性：99.5%以上
- 対応OS：iOS 16以上、Android 12以上
