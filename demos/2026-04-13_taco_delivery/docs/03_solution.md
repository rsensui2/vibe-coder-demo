# 03. ソリューション（Solution）

## TacoRunが提供する5つの解決策

---

### コアバリュープロポジション

> **「注文3分・調理15分・配達15分。合計33分で本場の味を、あなたのドアまで。」**

TacoRunは単なるデリバリーアプリではなく、**メキシカンフード文化の体験プラットフォーム**として設計されている。ユーザーは注文から配達まで途切れることなく「本格タコス体験」に没入できる。

---

### 解決策 1: メキシカン特化 店舗検索・発見体験

**課題**: 総合型プラットフォームでメキシカンレストランを探しても、検索結果が少なく、料理の詳細が分からない。

**解決**:
- タコス・ブリトー・ナチョス・エンチラーダ・チュロス等のサブカテゴリで絞り込める専用検索エンジン
- スパイス度（🌶️ マイルド / 🌶️🌶️ スパイシー / 🌶️🌶️🌶️ 激辛）によるフィルタリング
- 「今から30分以内に届く店」「TacoPass対応店」「ベジタリアン対応」等のスマートフィルター
- 各店舗に「TacoRun認定シール」を発行し、品質基準を可視化（本格メキシカン認定・ハラール対応・オーガニック食材使用等）

店舗はこのプラットフォームに登録するだけで「メキシカンを探しているユーザー」に直接リーチできる。

---

### 解決策 2: カスタムトッピング 11種システム

**課題**: 大手プラットフォームでは「備考欄に書く」程度しかカスタマイズできず、店側も対応しにくい。

**解決**:
- アプリ内でトルティーヤ種（コーントルティーヤ / フラワートルティーヤ）を選択
- 11種のトッピングをビジュアルグリッドUIでチェックボックス選択
  - アボカド / チーズ / パクチー / 玉ねぎ / サルサ / ハラペーニョ / ライム / レタス / サワークリーム / グワカモーレ / コーン
- スパイス度（マイルド・スパイシー・激辛）の3段階設定
- カスタマイズ内容は注文データとして店舗の調理画面にリアルタイム表示（ミス削減）
- 人気カスタマイズのプリセット保存機能（「いつものMy Taco」）

これにより「自分だけのタコス」体験を実現し、リピート率向上に直結させる。

---

### 解決策 3: リアルタイム GPS 追跡

**課題**: 「今どこにいる？」が分からない配達不安が、注文体験を損なう。

**解決**:
- 注文確認 → 調理開始 → 調理完了 → ピックアップ → 配達中 → 到着 の6ステップをリアルタイムで可視化
- 配達員の現在地を地図上で秒単位追跡（自社開発SDKによる高精度測位）
- プッシュ通知「あと5分で到着」「ドアの前に到着しました」
- 配達員プロフィール（顔写真・評価・配達件数）の事前表示で安心感を提供
- 配達員とのアプリ内チャット・通話機能（個人電話番号を非開示）

DoorDash・Grabのトラッキング体験を参考に、日本市場向けにUI/UXを再設計。特に夜間注文・マンション配達に特化したアクセスコード共有機能を実装予定。

---

### 解決策 4: TacoPass サブスクリプション

**課題**: 配達料金が積み重なり、ヘビーユーザーのコスト感が高くなる。プラットフォームへのロイヤリティが低い。

**解決**:

| プラン | 月額 | 主な特典 |
|--------|------|----------|
| スタンダード | 無料 | デリバリー料金 ¥250〜 |
| TacoPass | ¥980 | デリバリー完全無料 + 毎週タコス1個無料クーポン |
| TacoPass Pro | ¥1,980 | デリバリー完全無料 + 毎日タコス1個無料 + VIP優先注文 + 誕生月特別クーポン |

週に3回以上注文するユーザーはTacoPassに加入すると配達料だけで元が取れる計算になる（¥250×4回 = ¥1,000 > ¥980）。無料タコスクーポンを加えると、経済的メリットは明確。

**ロイヤリティ設計**:
- 累計注文数に応じてバッジ付与（Taco Novice → Taco Master → Taco Legend）
- TacoPass Pro限定：新店舗オープン情報の先行通知
- 友人招待で双方に無料タコスクーポン（バイラル拡散設計）

---

### 解決策 5: レビュー & 写真シェア コミュニティ

**課題**: SNS映えするタコスなのに、デリバリーアプリ内での共有体験がなく、口コミが広がりにくい。

**解決**:
- 配達完了後に「タコス写真を投稿」するプロンプト表示（投稿率向上のUX設計）
- アプリ内フィードで友達のタコス投稿を閲覧（インスタ風）
- 写真投稿→次回注文クーポンプレゼント（行動インセンティブ）
- 「今週の映えタコス」ランキングを毎週更新し、ホーム画面に掲載
- Instagram / TikTok への一発シェア機能（TacoRunのウォーターマーク付き → ブランド拡散）
- 店舗側も自店のレビューにリプライ可能（コミュニケーション促進）
