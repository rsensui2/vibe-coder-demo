# Tsumugi（紡ぎ） デザインガイドライン

## プロダクト世界観

Tsumugi は「点を、放り込むだけ。線は、AIが紡ぐ。」を掲げる **アイデア・コネクター**。複数プロジェクト・複数クライアントを並走する経営者／コンサル／フリーランスのために、脳内に散乱した断片（dot）を AI がバックグラウンドで横断解析し、一見無関係な点と点の隠れた関連を発見して「ビジネスの種（thread）」に紡ぐ。

世界観の核は **「紡ぐ」= バラバラの繊維を撚り合わせて一本の糸にする日本の伝統技術**。整理を放棄し、関連発見を AI に全振りする思想。和の手仕事の静けさ・温かみと、AI の知的な精緻さを両立させる。

ターゲット: 複数案件並走者（コア）／新規事業担当・投資家・リサーチャー（セカンダリ）／繋がらないアイデアを抱える全クリエイター（ライト）。

## タイポグラフィ

- 見出し: `Shippori Mincho`, `Noto Serif JP` 系の **明朝体**。和の品格と編集的な静けさ。「紡ぎ」「点」「線」など漢字一字を大きく扱う。
- 本文: `Noto Sans JP`, `Inter` 17px+、行間 1.8。
- アクセント: 朱の小さな結び目ドット、金糸の細い曲線、縦書きの一文（CSS `writing-mode`）を装飾に使う。

## ビジュアル方針

- 和紙テクスチャ（CSS グラデーション＋微細ノイズで表現、画像不使用）
- **点（dot）と線（thread）のグラフ表現**: 散在する朱の小円（点）を金糸の曲線（SVG path / CSS）が撚り合わせる。これがブランドの中心ビジュアル。
- 織物・格子のモチーフ（CSS `repeating-linear-gradient` で経糸緯糸を表現）
- アイコンは線の細いミニマル線画（Lucide 系）
- 写真・3D・パーティクル・Canvas は使用しない
- 余白を大きくとり、編集デザイン誌のような静かな間（ま）を最優先

## ヒーロー要素

- 中央に「点が放り込まれ、金糸が紡がれていく」静止グラフィック（朱の点 → 金糸の曲線 → thread カード）
- キャッチコピー「点を、放り込むだけ。線は、AIが紡ぐ。」を明朝体で大きく
- スマートフォンモック（CSS のみ）に dot 投入画面を表示

## トーン

- 静謐で品のある宣言文（「整理しない。放り込むだけ。」「あなたが忘れた頃に、AIが繋ぐ。」）
- 過度なマーケ言葉禁止（"革命的""世界初" は使わない）
- 日本の手仕事の語彙を許容（紡ぐ・撚る・繊維・糸・織る・点と線）
