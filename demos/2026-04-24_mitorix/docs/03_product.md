# 03. Product

## Mitorix アーキテクチャ

### Hardware Layer
- **AIカメラ**: Jetson Orin Nano搭載のエッジデバイス（一体型）
- **設置**: ピッキング台上方に後付けアーム（工事不要、既存設備に取り付け）
- **電源**: USB-C給電（専用電源工事不要）
- **ネットワーク**: Wi-Fi / 有線LAN どちらも対応

### Software Layer
- **Edge Inference**: TensorRT最適化YOLOv10 + 独自薬剤認識モデル
- **Cloud Backend**: AWS Tokyo region（監査ログ保存・統計）
- **Client App**: 薬剤師向けiPadアプリ + 経営者向けWebダッシュボード

### AI Model Stack
1. **処方箋OCR**: Gemini 3.1 Pro Vision（日本語処方箋特化ファインチューン）
2. **薬剤画像認識**: 独自モデル（12,000種類の医薬品画像データセットで学習）
3. **数量カウント**: Detectron2ベースのセグメンテーションモデル
4. **類似薬判別**: 画像類似度 + 文字類似度の複合判定

## 5つの主要画面

### ① Home（ホーム）
- 「Good evening, 田中薬剤師」挨拶
- 今日の監査実績: 処方200件・不一致検出3件・ヒヤリハット予防
- 最新アラート3件（直近検出の不一致）

### ② Live Match（ライブ照合）
- 画面上部：処方箋OCR結果（薬剤名・規格・数量）
- 画面中央：AIカメラビュー（調剤中の薬剤をリアルタイム表示）
- 判定バッジ：**一致** (ミント) / **要確認** (コーラル) / **数量不足** (ゴールド)
- 音声通知：「一致しました」「アムロジピン5mgは処方と異なります、アムロジン2.5mgが必要です」

### ③ Alerts（アラート履歴）
- 今日〜過去30日の不一致検出ログ
- 各カード: 時刻 / 処方医 / 不一致内容 / 対応ステータス / 薬剤師コメント
- 例：「アムロジピン5mg → アムロジン2.5mg」「タケプロン15mg → タケキャブ10mg」

### ④ Report（レポート）
- 月次監査ダッシュボード
- 大きな数字表示: 監査件数 / 検出件数 / ヒヤリハット予防件数
- 棒グラフ: 日別推移
- ランキング: 処方医別の不一致傾向
- 経営者向け: ROI試算・医療事故賠償リスクの定量化

### ⑤ Settings（設定）
- 薬剤師プロファイル（資格番号）
- 連携レセコン情報
- 通知設定（音量・バイブ）
- プライバシー: 「データは院内保持・クラウド転送しない」オプション選択可

## セキュリティ・プライバシー設計

### HIPAA / 医療情報システムの安全管理ガイドライン 準拠
- データは院内LAN内で完結する運用モードを標準装備
- クラウド連携時は全データ暗号化（AES-256 / TLS 1.3）
- アクセス権限は薬剤師資格番号で管理
- 監査ログは *改竄防止ハッシュチェーン* で保存

### 処方箋画像の取り扱い
- OCR完了後、元画像は *24時間以内に自動削除*（設定変更可能）
- 患者個人情報は *最小限の構造化データ* のみ保持
- 厚労省「医療情報システムの安全管理に関するガイドライン 第6.0版」完全準拠

## 導入プロセス（最短3日）

**Day 1: 下見・設置**
- ピッキング台に合わせてAIカメラアームを取り付け（30分）
- Wi-Fi / LAN設定（15分）

**Day 2: レセコン連携**
- 主要レセコン（日レセ・MAPs・ファーマクラスター等）と連携
- テスト処方10件で動作確認

**Day 3: 運用開始 & スタッフ研修**
- 薬剤師向け1時間研修
- 運用開始
- 初月は専属カスタマーサクセスが伴走
