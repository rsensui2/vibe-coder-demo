# StyleMirror — サービス設計

## ユーザーフロー
1. 撮影: 店頭で気になる服をスマホで撮影
2. AI解析: 素材・色・シルエットを0.3秒で認識
3. コーデ提案: 手持ち服×新アイテムで5パターン提案
4. 購入: ワンタップで提携ECから決済

## 主要機能
- AIコーデ提案: 最大5パターン自動生成
- バーチャル試着: AR合成で体型に重ねて確認
- パーソナルカラー診断: 肌色×髪色からベストカラー判定
- クローゼット管理: 手持ち服を登録、重複購入防止

## 技術スタック
- フロントエンド: React Native、ARKit/ARCore、LiDAR API
- バックエンド: NEC画像認識エンジン、3Dボディモデリング、スタイルマッチングAI
- インフラ: NEC Cloud IaaS / Kubernetes
