# ペトモ — 市場調査

> 注: 以下の数値はデモ用の概算・仮説であり、正式な市場調査値ではない。

## 市場規模
- 国内のペット飼育世帯は約2,000万世帯規模。犬・猫の飼育頭数は合計1,500万〜1,600万頭規模で推移。
- ペット関連市場（フード・用品・医療・サービス）は約1.7兆円規模。うちペットケア・サービス領域は成長セグメント。
- ペットシッター・ホテルなど「預かり」関連は数百億円規模と推定され、ニーズに対し供給が逼迫。

## 追い風（マクロトレンド）
- 単身世帯・共働き世帯の増加 → 「ペットをひとりにできない」場面の増加。
- ペットの家族化（ファミリー化）→ 「知らない場所・人に預けたくない」心理の強まり。
- シェアリングエコノミー／ご近所共助サービスへの受容性向上。
- ペット可マンションの増加と、管理組合のコミュニティ施策ニーズ。

## ターゲットセグメント
| セグメント | 特徴 | 刺さるポイント |
|---|---|---|
| 単身×出張多めの飼い主 | 預け先に常に困る | 近所・低コスト・即マッチ |
| 共働き子育て世帯 | 急な用事が多い | 同じ建物の安心・写真見守り |
| シニア飼い主 | 通院・入院時に困る | 顔の見えるご近所・サポート |
| あずかり手（ペット好き） | 動物と触れ合いたい | やさしさポイント・お礼 |

## 競合と差別化
- ペットホテル: 高コスト・移動ストレス・一回限り。
- 既存シッターマッチング: 距離も人柄も不透明、心理的ハードル高。
- **ペトモの差別化**: 「同じ建物・ご近所」という物理的近さ＋顔が見える継続関係＋やさしさポイントの相互扶助。価格競争ではなく“信頼と温度感”で勝つ。

## リスクと対応
- 事故・トラブル時の責任 → 規約整備・あずかり保険・サポート窓口。
- 初期の供給密度不足 → マンション単位の一括導入で密度を先に作る。
- 信頼の毀損 → eKYC・建物認証・厳格なレビュー運用。
