# ペトモ — 機能仕様

## コア機能

### 1. ご近所マップ検索
- 自分の住む建物・地域を中心に、あずかり可能な飼い先を地図とリストで表示。
- 「同じ建物」「徒歩◯分」など距離でソート。対応動物（犬／猫／小動物）、サイズ、留守番可否などで絞り込み。

### 2. ペット＆飼い主プロフィール
- ペットの種類・性格・既往歴・好きなこと・苦手なことを登録。
- 飼い主自身の自己紹介、飼育歴、あずかり可能条件を掲載。「顔が見える」ことが安心の起点。

### 3. チャット予約
- マッチング相手と事前にチャットで相性・受け渡し方法・緊急連絡先を相談。
- カレンダーから日時を選んで予約。受け渡し場所（建物エントランス等）も指定。

### 4. 写真レポート見守り
- あずかり中、預かった人が写真・短文で様子を投稿。飼い主はタイムラインでリアルタイムに見守れる。
- 「ごはん完食」「お散歩いってきました」などワンタップ報告も。

### 5. やさしさポイント（相互扶助エンジン）
- あずかった分だけ貯まり、自分が預けたいときに使える「相互扶助」の通貨。
- お金だけに依存しない、助け合いのループを設計。ランキングやバッジでご近所貢献を可視化。

## 安心・信頼の仕組み
- 本人確認（eKYC）＋建物・地域認証で「実在のご近所」だけが参加。
- 相互レビューによる信頼スコア。預かり実績・レスポンス・マナーを評価。
- あずかり中の緊急連絡・サポート窓口、提携動物病院への一次連絡フロー。
- プレミアム会員にはあずかり保険を付帯。
