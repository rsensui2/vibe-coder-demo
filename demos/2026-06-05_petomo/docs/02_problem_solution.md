# ペトモ — 課題とソリューション

## 解決したい課題

### 1. 預け先がない・見つからない
急な出張、旅行、入院、残業。ペットを置いて出られない場面は日常的に発生するのに、頼れる預け先がない。家族や友人が近くにいない単身・核家族では特に深刻。

### 2. ペットホテルは高い・遠い・ストレス
1泊5,000〜10,000円と高額。人気店は予約が取りづらい。慣れない場所・知らない人・他の動物との接触は、ペットにとって大きなストレスになる。

### 3. 知らないシッターへの不安
既存のシッターマッチングは「他人が自宅に上がる／遠方の他人に預ける」ことへの心理的ハードルが高い。相手の人柄も生活圏も分からないまま、家族同然のペットを託すのは怖い。

### 4. ご近所のペット好きとつながれない
同じマンション・地域に「動物好き」「預かってもいい」という人は確実にいる。だが、誰がそうなのか可視化されておらず、声をかけるきっかけもない。

## ソリューション: ご近所共助プラットフォーム「ペトモ」

### コア発想
**「遠くの専門業者」ではなく「すぐ近くの信頼できる誰か」に預ける。**
同じ建物・同じ地域という物理的近さが、低コスト・移動ゼロ・顔が見える安心を同時に実現する。

### 仕組み
1. ペットと自分のプロフィールを登録（建物・地域を認証）。
2. ご近所の「あずかってもいい」飼い主を地図とリストで探す。
3. チャットで相性・条件を相談し、日時を予約。
4. 引き渡し後は写真付きレポートでリアルタイムに見守る。
5. 相互レビューで信頼スコアが貯まり、次のマッチングがより安心に。

### 既存サービスとの違い
| | ペットホテル | 一般シッターマッチング | **ペトモ** |
|---|---|---|---|
| 距離 | 遠い | バラバラ | **同じ建物・ご近所** |
| コスト | 高い | 中〜高 | **低い（共助）** |
| 安心の源泉 | 施設 | レビューのみ | **顔が見える関係＋レビュー** |
| 関係性 | 一回限り | 一回限り | **継続するご近所関係** |

### 北極星
「お金で解決するサービス」ではなく「やさしさをおすそわけし合うコミュニティ」。この温度感こそがペトモの堀（モート）になる。
