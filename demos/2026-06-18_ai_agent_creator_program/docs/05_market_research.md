# 05 市場調査 — AIエージェント人材市場

> 注: 本デモは企画・制作物の品質を示すためのもの。以下の数値は企画上の想定・仮説であり、実データに基づく投資判断には一次情報での裏取りが必要。

## 市場トレンド
- 生成AIの普及で「AIを使う」は一般化。次の主戦場は**自律的に動くAIエージェント**。
- 単発のプロンプトから、ツール連携・記憶・マルチエージェントで業務を継続実行する方向へシフト。
- 企業の関心は「導入」から「内製化（自社で作り運用する）」へ移行しつつある。

## 課題（需要の根拠・想定値）
- AI活用人材の不足: **約49万人（2030年予測）**規模のギャップ。
- エージェント関連市場: **年成長率 約44%**の高成長領域（想定）。
- エージェントを内製できる日本企業: **約7%**にとどまる（想定）。
→ 「作れる人材」の供給が決定的に足りていない。

## 競合マップ
| カテゴリ | 提供内容 | AGENT ACADEMIA との差 |
| --- | --- | --- |
| プロンプト講座 | 使い方中心 | 実装・運用まで踏み込まない |
| プログラミングスクール | 汎用開発 | エージェント特化ではない |
| 単発セミナー/書籍 | 知識インプット | ハンズオン・成果物が残らない |
| **AGENT ACADEMIA** | 設計→実装→デプロイ→ポートフォリオ | 「創る」に特化・成果物が残る |

## ターゲット規模（想定）
- 国内エンジニア人口＋AI内製を志向する非エンジニア層を母集団に、
- 「自分で作れるようになりたい」上位意欲層を初期ターゲットに設定。

## 参入機会
- 「日本初のAIエージェント・クリエイター養成」という先行者ポジション。
- 法人のAI内製化ニーズと卒業生供給をつなぐエコシステム化の余地。

## リスクと対応
- 技術トレンドの速い変化 → カリキュラムを四半期ごとに更新。
- 受講生のレベル差 → フェーズ制＋メンタリングで個別最適化。
- 「学んだが作れない」化の回避 → 卒業制作のデプロイを必須要件に。
