# 01 エグゼクティブサマリー — AGENT ACADEMIA

## 一行で
**AGENT ACADEMIA** は、日本初のAIエージェント・クリエイター養成プログラム。12週間で、AIを「使う側」から「創る側」へ転換させる。

## 背景
生成AIの普及で「AIを使える人」は急増したが、自律的に動くAIエージェントを**設計・実装・運用できる人材**は決定的に不足している。プロンプトを書けることと、業務を自動化するエージェントを内製できることの間には、大きなスキルギャップがある。

## 提供価値
- ゼロから自律AIエージェントを設計・実装・デプロイできる実装力。
- 現場と同じスタック（最新LLM・エージェントSDK・サーバーレス実行環境）でのハンズオン。
- 卒業制作をそのままポートフォリオ／転職・案件獲得につなげる導線。

## プログラム概要
- 期間: 12週間（オンライン＋スクーリング）
- 構成: 3フェーズ — FOUNDATION → BUILD → SHIP
- 開講: 2026年9月（第1期生募集）
- 料金: ベーシック ¥298,000 / スタンダード ¥498,000 / プロ ¥980,000

## ターゲット
- スキルを次の段階に進めたいエンジニア
- 自社業務を内製で自動化したい事業企画・非エンジニア
- AI時代に通用する武器が欲しい学生・若手

## ゴール
第1期で「自律エージェントを一人で創れる」修了生を輩出し、企業のAI内製化人材の供給源になる。

## タグライン
**AIに使われる側から、AIを創る側へ。** / Build Agents. Not just prompts.
