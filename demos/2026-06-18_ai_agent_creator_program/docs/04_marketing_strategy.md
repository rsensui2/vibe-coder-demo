# 04 マーケティング戦略 — AGENT ACADEMIA

## ポジショニング
「AIを使う研修」は飽和。AGENT ACADEMIA は**「AIを創る」唯一の養成プログラム**として明確に差別化する。
キーメッセージ: **AIに使われる側から、AIを創る側へ。**

## ターゲット・セグメント
1. **キャリアアップ志向のエンジニア**（25-35歳）: プロンプトの先の「設計力」を求める。
2. **内製化したい事業企画・非エンジニア**（30-45歳）: 自社業務を自動化したい。
3. **武器が欲しい学生・若手**（20-26歳）: 卒業制作を内定・実績に直結させたい。

## ファネル
1. **認知**: SNS技術発信・受講生の制作シェア・PR（「日本初」訴求）。
2. **興味**: 無料説明会／体験セミナー（本デモ一式＝LP・スライド・動画・モックが武器）。
3. **検討**: カリキュラム詳細・受講生の声・FAQ・料金比較。
4. **申込**: 期別募集の限定感（第1期生・定員）。
5. **継続/紹介**: コミュニティ・修了生ネットワーク・成果発信。

## チャネル別施策
- **動画CM（30秒）**: SNS広告・説明会冒頭・LPヒーロー。
- **LP 3パターン**: セグメント別/媒体別にABテスト（モダン/プレミアム/ポップ）。
- **音声**: 説明会導入・ポッドキャスト/SNSリール。
- **スライド**: 説明会・営業・法人提案。
- **モックアプリ**: 学習体験の具体イメージを提示。

## メッセージ・トーン
- 煽らない。実装力という「具体的な成果」で語る。
- 受講生の変化（before/after）をストーリーで見せる。

## ローンチ計画
- 募集開始: 2026年7月（説明会連動）
- 開講: 2026年9月（第1期）
- 早期申込特典・定員制で意思決定を後押し。

## 効果測定
説明会参加数 / 申込転換率 / CPA / LPパターン別CVR / SNSエンゲージメント。
