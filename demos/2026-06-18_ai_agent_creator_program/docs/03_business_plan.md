# 03 事業計画 — AGENT ACADEMIA

## 収益モデル
受講料（コホート型）を主軸に、法人研修・コミュニティ継続課金で積み上げる。

### 料金プラン
| プラン | 価格 | 内容 |
| --- | --- | --- |
| ベーシック | ¥298,000 | オンライン完結・録画アーカイブ・コミュニティ |
| スタンダード（人気） | ¥498,000 | ＋スクーリング・メンタリング・卒業制作レビュー |
| プロ | ¥980,000 | ＋1on1専属メンター・転職/案件サポート・無期限アクセス |

### 想定構成比（1コホート40名）
- ベーシック 40% / スタンダード 45% / プロ 15%
- 平均単価 約 ¥470,000 → 1コホート売上 約 1,880万円

## 成長プラン
- **Y1**: 第1期（40名）→ 年4コホート。実績とポートフォリオを蓄積。
- **Y2**: 募集規模拡大＋法人研修パッケージ提供開始。
- **Y3**: 企業のAI内製化支援（研修＋伴走）へ拡張。卒業生ネットワークを案件マッチングに。

## コスト構造
- 講師・メンター人件費（変動）
- 教材・プラットフォーム開発（固定・初期重め）
- 集客（広告・セミナー・SNS）
- クラウド/API実習費

## 集客チャネル
- 無料説明会・体験セミナー（本デモ一式が起点）
- SNS（技術発信・受講生の制作シェア）
- 法人向け（AI内製化ニーズへの直接提案）

## KPI
- 説明会→申込転換率
- 修了率・卒業制作デプロイ率
- 修了生の転職/案件獲得率（プロプランの価値根拠）

## 競合優位
- 「使う」研修が多い中で、唯一「創る（実装・運用）」に振り切る。
- 現場スタックでのハンズオン＋デプロイまで一貫。
- 卒業制作がそのまま実績になる導線。
