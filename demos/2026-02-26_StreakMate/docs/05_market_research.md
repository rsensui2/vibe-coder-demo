# StreakMate — 市場調査・競合分析

## 市場規模

### 習慣化・生産性アプリ市場（グローバル）
- 2024年: 約2,500億円
- 2029年予測: 約5,800億円（CAGR 18.3%）
- 日本市場: 約200〜300億円（2024年推定）

### ターゲットセグメント
1. **自己啓発層（25〜35歳）**: 読書・英語・筋トレ習慣化需要
2. **資格取得層（20〜40歳）**: TOEIC・簿記・プログラミング学習
3. **健康習慣層（30〜50歳）**: 運動・ダイエット・睡眠管理
4. **学生層（15〜22歳）**: 受験・定期テスト向け勉強記録

## 競合分析

### 主要競合

| アプリ | 強み | 弱み | StreakMateの差別化 |
|--------|------|------|-------------------|
| **Habitica** | ゲーミフィケーション | 複雑・学習コスト高 | シンプル操作 + AI応援 |
| **Streaks** (iOS) | デザイン・シンプル | AIなし・iOS限定 | AI + クロスプラットフォーム |
| **Duolingo** | 強力なストリーク | 語学特化 | 汎用習慣管理 |
| **Notion** | 柔軟性 | 設定が複雑 | 即座に使えるUX |
| **Finch** | 感情的サポート | ゲーム要素が強め | リアルなAIコーチ感 |

## 日本市場の特徴・機会

1. **勉強アプリへの親和性**: スタディプラス（MAU 100万人超）の成功が証明
2. **年間手帳文化**: 記録・振り返りを重視する文化的背景
3. **英語学習需要**: 社会人英語学習者が需要を牽引
4. **LINE連携**: 通知チャンネルとしてLINE活用で拡散力UP

## 成功事例から学ぶ

### Duolingo のストリーク戦略
- ストリーク機能導入後、DAUが**5倍**に増加
- 「ストリークを守るために毎日ログイン」する心理を最大活用
- → StreakMateはこれを習慣全般に応用

### Strava の社会的圧力効果
- フレンド機能で達成を公開 → 継続率が**3倍**に向上
- → チーム機能（Premiumプラン）で同様の効果を狙う
