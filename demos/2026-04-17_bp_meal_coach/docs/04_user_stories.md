# BP Meal Coach — ユーザーストーリー

## ペルソナ1: 田中 健一さん(48歳・営業部長)

**背景**
- 年収800万円、都内在住、既婚、子供2人
- 会社の健康診断で「収縮期血圧 148」、産業医から再検査を勧められた
- 出張が多く、外食中心の食生活
- 血圧計は買ったが、3日で挫折
- 降圧剤は飲みたくない

**利用シナリオ**
1. 朝出勤前、血圧計で測定 → スマホでスクショ → BP Meal Coachアプリで共有 → 自動記録
2. 昼のランチミーティング、とんかつ定食を撮影 → AIが「塩分5.2g、本日残り0.8g」と警告
3. 夕食は提案通り「焼き鮭 + 小松菜の煮浸し」を自宅で食べる → 塩分1.1g
4. 週末にレポートを見て「今週は平均130まで下がった」と実感
5. 妻にFamilyプランを勧められ、アップグレード

**成果(3ヶ月後)**
- 収縮期血圧: 148 → 131
- 体重: 78kg → 74kg
- 妻からも「食事の意識が変わった」と評価
- 産業医の再検査をクリア、降圧剤を回避

## ペルソナ2: 佐藤 美沙子さん(55歳・経営企画部)

**背景**
- 年収600万円、実家住まい(父85歳同居)
- 父が脳梗塞で倒れた経験から血圧管理に敏感
- 自身も更年期で血圧が不安定(朝は高め、夜は低め)
- 料理は自分で作るが、減塩レシピのバリエーションに限界

**利用シナリオ**
1. 朝・夜の血圧測定(更年期で変動が大きい)
2. AIが「朝の血圧が高い日は夕食の塩分を控えめに」とパーソナライズ指示
3. 手作り料理を撮影 → AIが「味噌汁の塩分2.1g、減らす余地あり」と指摘
4. アプリが提案する減塩レシピ(味噌を減らして昆布だしを強く等)を試す
5. 月次レポートを父のかかりつけ医に見せて、家族の血圧管理情報として活用

**成果(6ヶ月後)**
- 収縮期平均: 138 → 125
- 減塩レシピを10種マスター
- 家族全員の健康意識が向上

## ペルソナ3: 山本 幸夫さん(62歳・中小企業経営者)

**背景**
- 自社経営、年商3億円
- 接待・会食が多く、夜遅くの食事が日常
- 既に降圧剤を服用中、医師から減塩を厳命されている
- 健康管理アプリに懐疑的(最新ガジェットが苦手)

**利用シナリオ**
1. 娘にアプリを設定してもらう、血圧計連携も娘が代行
2. シンプルなUIで「撮るだけ」なので続けられる
3. 接待の会席料理を撮影 → AIが塩分10gと警告 → 明日一日は減塩メニュー徹底
4. かかりつけ医に月次PDFレポートを印刷して持参 → 医師との会話が深まる
5. Apple Watchで心拍も統合、運動量も見える化

**成果(1年後)**
- 収縮期: 155 → 138
- 降圧剤減量(医師判断)
- 娘にも同じアプリを勧める
