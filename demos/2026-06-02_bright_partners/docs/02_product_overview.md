# 02. Product Overview — サービス全体像

## 1. 経営コンサルティング（人の力）

- **経営戦略・財務支援**：事業計画の再設計、資金繰り・収益構造の見直し。
- **営業支援**：営業プロセスの仕組み化、トークスクリプト整備、成約率改善。
- **人材育成**：研修プログラム、評価制度設計、定着率向上の伴走。

特徴：戦略提案で終わらず、現場に入り「成果が出るまで」伴走する。

## 2. ITソリューション（ITの力）

### WinActor（RPA）
- 国産シェア上位の RPA ツール。プログラミング不要で業務を自動化。
- 対象業務：請求書処理、データ入力、受発注、定型レポート作成、Web情報収集 など。
- ブライトの役割：業務棚卸し → シナリオ設計 → 導入 → 定着まで支援。

### 指紋認証機能付きICカード
- 1枚で「入退室管理 / 勤怠打刻 / PCログイン」を統合。
- 指紋認証により、なりすまし・代理打刻を物理的に防止。
- セキュリティ強化と労務管理の正確性を同時に実現。

## 3. 自社ブランド「飲めルンです」

- 自社で企画・展開する商品ブランド。
- 「支援者であると同時に、自らも売る当事者」というポジションの証明。

## 構想：Bright Cockpit（統合経営ダッシュボード）

人とITの取り組みを一画面に集約する将来構想。

| モジュール | 表示内容 |
|-----------|---------|
| ホーム | 主要KPI（売上・稼働・コスト削減） |
| RPA | WinActorシナリオの稼働状況・削減時間 |
| 勤怠/入退室 | ICカードの打刻・入退室ログ |
| コンサル | 営業・人材育成プロジェクトの進捗 |

経営者がスマホひとつで「会社の今」を把握できる世界観。

## ロードマップ（イメージ）

- **Phase 1**：RPA・ICカード・コンサルの個別提供（現在）
- **Phase 2**：Bright Cockpit β（データ連携・可視化）
- **Phase 3**：AI活用の経営アシスト（異常検知・改善提案の自動化）
