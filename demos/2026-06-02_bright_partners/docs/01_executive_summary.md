# 01. Executive Summary — ブライトマネジメントパートナーズ

## 一言で

**人とITの両輪で、中小企業を一段上へ引き上げる経営パートナー。**
経営コンサルティング（人）と RPA・指紋認証ICカード（IT）を一社で一気通貫提供できることが最大の差別化。

## 事業ポートフォリオ

| 領域 | 内容 |
|------|------|
| 経営コンサルティング | 経営戦略・財務、営業支援、人材育成（伴走型） |
| ITソリューション | RPA「WinActor」導入支援、指紋認証ICカード販売 |
| 自社ブランド | 「飲めルンです」— 自らものづくり・販売を行う当事者 |

## 解く課題

日本の中小企業（全企業の99.7%）が直面する三重苦：
1. **人手不足・属人化** — 採用難と業務のブラックボックス化
2. **DX・デジタル化の遅れ** — 何から手をつけるか分からない
3. **売上の頭打ち** — 営業力・人材育成のノウハウ不足

これらは「人」だけでも「IT」だけでも解けない。両方を提供できる事業者は稀少。

## 競合優位性

- **戦略 → 実装まで一社完結**：コンサルは戦略止まり、SIerは実装止まりが多い中、ブライトは両方を担う。
- **当事者性**：自社ブランド「飲めルンです」を運営し、支援する側も「売る痛み」を知っている。
- **伴走型**：導入して終わりではなく、定着・成果まで現場に入り込む。

## KPI目標（イメージ例）

| 指標 | 目標 |
|------|------|
| RPA導入による定型業務削減 | 月 平均 160 時間/社 |
| 勤怠不正・打刻ミス | ほぼゼロ化 |
| 営業成約率の改善 | +20% |
| 顧客継続率 | 90%+ |

> ※数値は本デモ用のイメージ例。
