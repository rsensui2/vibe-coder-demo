# MAMORIO PLUS - 市場調査レポート

## 1. ユーザーリサーチ

### 調査概要
- 対象：全国の20〜60代スマートフォンユーザー
- サンプル数：n=1,200
- 調査手法：オンラインアンケート + デプスインタビュー（n=30）
- 調査期間：2025年11月〜12月

### 主要発見

#### 忘れ物の実態
```
月1回以上の忘れ物経験: 73%
週1回以上: 31%
ほぼ毎日: 8%

最もよく忘れるアイテム（複数回答）:
1位. 鍵（家の鍵・車の鍵）     68%
2位. 財布・カードケース        62%
3位. スマートフォン            45%
4位. 傘                       41%
5位. 仕事の書類・荷物          38%
```

#### 既存トラッカーの利用状況
- 現在利用中：18%
- 過去に利用したが辞めた：12%（理由：電池切れが面倒、精度が不満）
- 利用したいが未購入：35%（理由：価格、機種変での使えなくなる不安）

#### 機能需要調査（「あったら使いたい」）
| 機能 | 需要率 |
|------|-------|
| 精密測位（10cm以内） | 78% |
| 忘れる前の事前通知 | 71% |
| 玄関出る前のアラート | 69% |
| スマートホーム連携 | 45% |
| プライバシー保護 | 83% |

## 2. 競合分析詳細

### Apple AirTag（2021〜）

**強み:**
- iPhone / Findネットワーク（10億台以上）との親和性
- 精密なUWB測位（iPhone 11 Pro以降）
- デザインの洗練度
- Apple Storeでの購入しやすさ

**弱み:**
- iOS専用（Android非対応）
- 電池交換はCR2032（ユーザー任せ）
- ビジネス向け管理機能なし
- ストーキング問題への社会的批判
- 日本でのFindネットワーク密度は未公開

**MAMORIO PLUSが勝てるポイント:**
- Android対応でユーザー層拡大
- 日本特化ネットワーク（鉄道・バス連携）
- ビジネス管理機能
- AI予測機能（AirTagにはない）
- プライバシー保護の透明性

---

### Tile（2013〜、現在はLife360傘下）

**強み:**
- iOS/Android両対応
- 長い歴史とブランド認知
- 複数製品ライン（スリム・スタイル・スティッカー等）

**弱み:**
- 日本市場でのネットワーク密度が低い
- UWB未搭載（Bluetooth精度のみ）
- AI機能なし
- Life360によるデータ収集への懸念

---

### MAMORIO（現行版）

**強み:**
- 日本最大のネットワーク（鉄道700路線以上）
- 日本語サポートの充実
- カード型など多様なフォームファクター

**弱み（PLUSで解決）:**
- UWB未搭載（精度1〜3m）
- AI予測機能なし
- スマートホーム連携なし
- ビジネス向け機能の不足

## 3. 市場トレンド

### IoT × AI の融合加速
2025年以降、単純なトラッカーから「予測型」への進化がトレンド。
スマートフォンのオンデバイスAI（Apple Neural Engine / Google Tensor）の高性能化により、
プライバシーを守りながら高度な予測が可能になった。

### UWBの普及
- 2024年時点でUWB対応iPhone：iPhone 11 Pro以降（全iPhoneの約65%）
- Android：Pixel 6以降、Galaxy S21以降にも搭載
- 2026年には市場の80%以上がUWB対応デバイスになる見込み

### スマートホーム市場の拡大
- 日本のスマートホームデバイス普及率：2024年 15% → 2028年予測 35%
- Nature Remo：国内累計出荷200万台突破
- SwitchBot：日本市場で急成長

### ビジネスIoTの本格化
- 中小企業の資産管理DX需要が高まる
- コロナ後のオフィス縮小・リモートワーク化でモノの所在把握が困難に
- IT導入補助金対象製品としての認定を目指す

## 4. ターゲットペルソナ詳細

### ペルソナA: 多忙なビジネスパーソン「田中健二（43歳、部長）」
- 都内のコンサルティング会社勤務
- 月10日以上の出張・外回り
- 高品質なガジェットへの投資意欲高い（iPhone最新機種 / MacBook Pro）
- 悩み：複数のカバンを使い分けるため、鍵・名刺入れを入れ忘れる
- **需要機能:** UWB精密測位・AI予測・スマートホーム（玄関ドアアラート）
- **支払い意欲:** ¥4,000タグ + ¥380/月サブスク（年間コスト約¥8,560）

### ペルソナB: 親の持ち物を心配する「山田麻衣（36歳、会社員）」
- 母親（71歳）が最近物忘れが増えてきた
- 実家は電車で1時間。毎日心配している
- スマートフォンに詳しくないため、親が使いやすいシンプルさが必要
- **需要機能:** ファミリー共有・位置共有・バッテリー通知
- **支払い意欲:** ¥14,800（FamilyパックでタグをWi-Fi全体に設置）

### ペルソナC: 企業の資産管理「木村達也（51歳、総務部長）」
- 従業員500名の製造業
- PCやAV機器・工具類の所在把握が課題
- ERPシステム（SAP）を導入済み
- **需要機能:** Webダッシュボード・API連携・CSV一括登録・レポート機能
- **支払い意欲:** ¥2,500/個/月 × 200個 = ¥500,000/月

```
「このようなデバイスに支払える価格は？」（n=456名、購入意向あり）

〜¥2,000:     8%
¥2,001〜3,000: 22%
¥3,001〜5,000: 41%  ← 最多
¥5,001〜8,000: 20%
¥8,001以上:    9%

→ ¥3,980のSTARTERは最適プライシング
```
