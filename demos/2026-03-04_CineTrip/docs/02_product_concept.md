# CineTrip - プロダクトコンセプト

## コアバリュー

### 「映画は、旅になる。」

映画鑑賞という個人的な体験を、コミュニティ×旅行という形で昇華させる。
「一人で映画を観て終わり」から「仲間と非日常の場所で観て、語らい、思い出になる」へ。

## ユーザージャーニー

### Before CineTrip
```
映画を観たい → 一人で映画館へ → 鑑賞 → 終了（感想を言う相手なし）
旅行したい → 一緒に行く人がいない → 断念 or 一人旅
```

### After CineTrip
```
映画を観たい → CineTripでイベント検索
           → 映画仲間と出会う
           → 温泉地・古民家シアターへリトリート旅
           → 一緒に鑑賞・語らい
           → 旅ログ・レビュー・思い出シェア
           → 継続的な映画仲間コミュニティへ
```

## 体験の特徴

### 1. 映画×リトリートの融合
- 温泉旅館の大広間でのプロジェクター上映
- 古民家をリノベーションしたシアタースペース
- 湖畔・海辺の野外映画祭スタイル
- 山小屋でのサウナ×映画マラソン

### 2. コミュニティの深度
- 映画の好みによる精度の高いマッチング
- 旅を共にすることで生まれる深いつながり
- 「映画仲間」から「旅仲間」へ進化

### 3. 体験のキュレーション
- ホストがイベントテーマを設定（「ミステリー映画特集」「黒澤明オールナイト」など）
- 旅行手配・映画選定・宿手配のワンストップ
- 参加者のレビュー・写真でコンテンツが蓄積

## ネーミングの意図

**CineTrip = Cinema（映画）× Trip（旅）**

- 覚えやすく、サービスの本質を一言で表現
- 英語表記で国際展開を見据えた汎用性
- 「シネトリップ」と読む。リズムがよく口に出しやすい
