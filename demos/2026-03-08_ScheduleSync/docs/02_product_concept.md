# 02 プロダクトコンセプト

## なぜ今、日程調整を再発明するのか

### 既存ツールの限界
- **Calendly**: 相手も使ってないといけない。一方向的。
- **調整さん**: グリッドを全員が手動で埋める必要がある。
- **Teams/Meet**: 招待を送るだけ。都合の確認は別途必要。

### ScheduleSyncの差別化
1. **AIが「全員の予定を読む」** — 相手のカレンダーに直接アクセスし、空き時間を自動検出
2. **自然言語インターフェース** — フォームもグリッドも不要。話しかけるだけ
3. **プロアクティブ提案** — ユーザーが依頼する前に「明日の空き時間はここです」と提案
4. **会議の前後まで自動化** — 予約→アジェンダ作成→リマインダー→議事録テンプレートまで一気通貫

### ターゲットユーザー
- **プライマリ**: フリーランス・個人事業主（月980円で全問題解決）
- **セカンダリ**: 中小企業チームリーダー（チームプラン）
- **エンタープライズ**: 大企業の事務局・秘書（カスタムプラン）

### 技術スタック（Vibe Coding版）
- フロントエンド: Next.js + Tailwind CSS
- バックエンド: FastAPI（Python）
- AI: Claude API（自然言語解析）
- カレンダー連携: Google Calendar API、Microsoft Graph API
- DB: Supabase（PostgreSQL）
