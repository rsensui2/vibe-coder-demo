# ScheduleSync デザインガイドライン

## コンセプト
「調整の摩擦をゼロに」— 日程調整という非生産的な往復をAIが完全排除し、"会いたい瞬間"がそのまま実現する次世代スケジューリングプラットフォーム。

## カラーパレット（Pattern 1: メイン）
- Background: #0A0E1A（ディープネイビー）
- Primary: #6C63FF（エレクトリックパープル）
- Accent: #00D9FF（サイバーシアン）
- Surface: #121829（ダークカード）
- Text: #F0F4FF（オフホワイト）
- Subtext: #8892A4（グレイッシュブルー）
- Success: #00E5A0（ミントグリーン）

## タイポグラフィ
- フォント: Inter, 'Noto Sans JP', sans-serif
- 見出し: 48-72px / font-weight: 800
- 本文: 16-18px / line-height: 1.7
- ラベル: 13px / letter-spacing: 0.08em / uppercase

## ブランドトーン
- **キャッチコピー**: 「もう、調整しない。」
- **サブコピー**: AIが空気を読み、全員の予定を瞬時に同期。日程調整は過去のものになる。
- **ブランドボイス**: テクノロジーの力を信じる・シンプルを極める・摩擦を憎む

## UIスタイル
- グラスモーフィズム × ニューモーフィズムのハイブリッド
- 微細なパーティクルは不使用（パフォーマンス重視）
- アニメーション: CSS transition/transformのみ
- カードUIに backdrop-filter: blur(20px) + border: 1px solid rgba(255,255,255,0.08)

## サービス機能（5大特徴）
1. **AI自動最適化**: 全員のカレンダーを読み込み、最適日時を瞬時提案
2. **自然言語入力**: 「来週の午後、3人で1時間」で完結
3. **マルチプラットフォーム同期**: Google/Outlook/Appleカレンダーをリアルタイム統合
4. **会議室AI自動予約**: オフィス・会議室も一括手配
5. **事前アジェンダ生成**: 会議の目的からAIが議題案を自動作成

## 料金プラン
- Free: 月5回まで / 1対1のみ
- Pro: ¥980/月 / 無制限 / 最大10名 / AI優先最適化
- Team: ¥4,980/月（5名〜） / 全機能 / 会議室連携 / SLA保証
