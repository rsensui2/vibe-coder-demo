# 座組・ステークホルダー・オペレーション — WellBridge Loan

## 1. 4者の役割

| ステークホルダー | 役割 | 主な責任 |
|------------------|------|----------|
| 金融機関 | 貸し手 | 与信審査、融資実行、金利設定、金利収益の獲得 |
| 商工会議所 | 企画・運営主体 | プラットフォーム運営、加盟管理、審査基準の標準化、金融機関マッチング |
| 事業所（企業） | 給与天引き協力主体 | 在籍確認、収入情報の管理、給与天引きと送金、退職・異動対応 |
| 従業員 | 借り手 | 借入申込、返済（給与天引き）、口座登録 |

商工会議所は融資を行わず金融リスクを負担しない。あくまで運営プラットフォーマーとして手数料収益を得る。

## 2. 事業スキーム図

```
        融資実行
[金融機関] ───────────────> [従業員（借り手）]
   ^                              │
   │ 返済金送金                    │ 給与天引き同意
   │                              v
   └──────────── [事業所（企業）] <── 給与天引きで返済回収
                      ^
                      │ 加盟・運営・システム提供
              [商工会議所（運営主体）]
                      │
                      └── 金融機関マッチング・審査基準標準化
```

## 3. オペレーションフロー

### 3.1 加盟フェーズ
1. 商工会議所が加盟企業にサービスを案内、加盟契約を締結
2. 事業所が従業員情報（雇用形態・勤続年数・給与レンジ）を管理画面に登録
3. 事業所の給与計算システムと天引き連携を設定

### 3.2 申込・審査フェーズ
1. 従業員がアプリで借入申込（金額・目的・必要書類）
2. 事業所が在籍確認・収入証明を承認
3. 商工会議所が申込データを金融機関にルーティング
4. 金融機関が4層審査（後述・`05`参照）を実施し、可否・金利・上限を決定
5. 従業員が電子契約を締結、融資実行

### 3.3 返済フェーズ（在籍中）
1. 毎月の返済期日に事業所が給与から天引き
2. 事業所が金融機関へ返済金を送金（一括または個別）
3. 金融機関が入金照合、商工会議所が残高・延滞をモニタリング

### 3.4 退職・転職フェーズ
1. 退職予定が判明したら事業所が退職通知を登録
2. 退職前に従業員へ通知、本人名義口座からの自動引落（口座振替）へ切替
3. 残高不足時は複数回引落・督促フローを実行
4. 転職先が加盟・天引き協力可能なら給与天引きへ再切替（将来拡張）

## 4. 契約関係

- 商工会議所 ↔ 事業所: 加盟契約（手数料、天引き協力義務、データ取扱い）
- 商工会議所 ↔ 金融機関: 業務提携契約（紹介、システム連携、手数料）
- 金融機関 ↔ 従業員: 金銭消費貸借契約（融資の主契約）
- 従業員 ↔ 事業所: 給与天引きに関する同意（労使協定・本人同意）

## 5. 各ステークホルダーの動機（インセンティブ設計）

- **事業所**: 福利厚生強化と人材定着。天引き処理の負担にはシステム連携と手数料・インセンティブ設計で対応
- **金融機関**: 給与天引きによる回収確度の向上、優良ポートフォリオ、地域貢献のレピュテーション
- **従業員**: 低金利・簡便性・雇用主経由の安心感
- **商工会議所**: 加盟企業支援の深化、手数料収益、ネットワーク価値の向上

## 6. オペレーション上の主要論点

- 事業所の天引き処理負担の最小化（給与システム連携の標準化）
- 退職時の回収経路の確実な切替
- 複数金融機関が参加する場合の審査基準・契約雛形の標準化
- 個人情報・収入情報の取扱いに関する事業所・商工会議所・金融機関の責任分界
