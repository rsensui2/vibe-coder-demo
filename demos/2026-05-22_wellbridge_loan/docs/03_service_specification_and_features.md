# 機能一覧・サービス仕様 — WellBridge Loan

## 1. サービス概要

WellBridge Loan は、従業員（借り手）・事業所（企業）・金融機関・商工会議所の4者が利用するWebおよびモバイルベースのSaaS型プラットフォームである。各ステークホルダーに専用の画面・権限を提供する。

## 2. 従業員向け機能（モバイルアプリ）

| 機能 | 内容 |
|------|------|
| ホーム/ダッシュボード | 借入可能枠、現在の借入残高、次回返済日、返済進捗 |
| 借入申込 | 金額スライダー、利用目的選択、金利・月々返済額の即時表示、必要書類アップロード |
| 返済シミュレーション | 借入額 × 返済期間で月々返済額・総返済額を試算 |
| 返済状況 | 給与天引き履歴のタイムライン、残高グラフ、繰上返済 |
| 口座管理 | 給与口座、退職時の引落口座（本人名義）の事前登録 |
| プロフィール/設定 | 勤務先情報、通知設定、本人確認 |
| 金融リテラシー支援 | 借入目安、家計バランス診断、相談予約 |

## 3. 事業所向け機能（管理画面）

| 機能 | 内容 |
|------|------|
| 従業員管理 | 在籍確認、雇用形態・勤続年数・給与レンジの登録 |
| 天引き処理 | 月次の天引き対象一覧、給与システム連携、送金実績の確認 |
| 退職・異動対応 | 退職通知、引落口座への切替トリガー、転職時の再切替申請 |
| レポート | 利用状況サマリ、福利厚生効果のレポート |
| 権限管理 | 人事担当者の権限設定、監査ログ |

## 4. 金融機関向け機能

| 機能 | 内容 |
|------|------|
| 審査連携 | 標準化された審査APIによる申込データ受領・審査結果返却 |
| 融資管理 | 融資実行、残高・回収状況のモニタリング |
| 回収ステータス | 給与天引き／口座振替の入金照合、延滞アラート |
| 共通契約雛形 | 商工会議所が用意する標準契約テンプレートの利用 |

## 5. 商工会議所向け機能（運営者）

| 機能 | 内容 |
|------|------|
| 加盟管理 | 加盟企業の登録・契約・手数料管理 |
| 審査基準管理 | 共通スコアリングルールの設定・更新 |
| ダッシュボード | 全体KPI（残高、延滞率、利用率）の可視化 |
| 金融機関マッチング | 複数金融機関への申込ルーティング |

## 6. 借入商品の仕様（案）

| 利用シーン | 想定用途 | 借入上限（案） |
|------------|----------|----------------|
| 生活安定 | 医療費、冠婚葬祭、修繕費 | 50万円 |
| 教育 | 子どもの学資、資格取得 | 100万円 |
| 緊急 | 災害、失業期間中のつなぎ | 30万円 |
| 資産形成支援 | 住宅関連費用（付帯） | 200万円 |

- 返済方式: 元利均等、給与天引きによる月次返済
- 金利: 給与天引きによる回収リスク低減を前提に、消費者金融・カードローンより低位に設定（金融機関が決定）
- 借入上限: 利用目的別の上限に加え、家計バランスに基づく総量制限

## 7. 返済メカニズムの仕様

1. **在籍中**: 返済期日に事業所が給与から天引きし、金融機関へ一括または個別送金
2. **退職時**: 事前登録した本人名義口座からの自動引落（口座振替）へ切替。退職前通知と複数回引落で残高不足に対応
3. **転職時**: 新事業所が加盟・天引き協力可能な場合は給与天引きへ再切替（将来拡張）

## 8. システム連携要件

- 給与計算システムとの連携（CSV連携 → API連携へ段階的に高度化）
- 信用情報機関（CIC等）との照会連携
- 金融機関の融資管理システムとの審査API連携
- 本人確認（eKYC）、電子契約サービスとの連携

## 9. 非機能要件（概要）

- セキュリティ: 個人情報・金融情報の暗号化、アクセス権限管理、監査ログ
- 可用性: 月次の天引き処理を確実に行えるバッチ信頼性
- 拡張性: 商工会議所単位のマルチテナント構成、複数金融機関対応
