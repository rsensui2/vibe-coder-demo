# わんとなり — プロダクト仕様

## コンセプト
「ご近所の信頼」をUIに落とし込む。検索・予約・コミュニケーション・安心の4軸で設計する。

## 主要機能

### 1. ご近所マッチング
- 位置情報・建物・徒歩圏でフィルタした「あずかり可能な飼い主」リスト＆地図表示
- 犬種相性、サイズ、性格タグ（吠えにくい・多頭OK・小型限定など）でレコメンド
- 空き時間カレンダーで「今あずかれる人」を即座に把握

### 2. 予約・引き渡しフロー
- チャットで事前すり合わせ → 日時確定 → 予約成立
- 引き渡しチェックリスト（フード・薬・散歩頻度・連絡先）を自動生成
- QRまたはコードで引き渡し・返却を記録

### 3. あずかりレポート
- あずかる側が散歩・食事・様子を写真＋コメントで共有
- 飼い主はリアルタイムで愛犬の様子を見守れる

### 4. ポイント循環（信用＝通貨）
- あずかると「わんポイント」が貯まり、あずける時に使える
- 現金決済も選べるハイブリッド（プレミアム会員は換金レート優遇）

### 5. 安心・安全レイヤー
- 本人確認（eKYC）＋住所・マンション認証
- ワクチン接種証明のアップロード必須
- 双方向レビュー＆通報機能
- 預かり中の事故に備えるペット保険を標準付帯

## ユーザー種別
- **あずける人**：外出時に近所に頼みたい飼い主
- **あずかる人**：在宅時間が長く、犬とふれあいたい／ポイントを貯めたい飼い主
- ほとんどのユーザーは両方を兼ねる（相互扶助モデル）

## 技術スタック（想定）
- モバイル：React Native（iOS / Android）
- バックエンド：Node.js + PostgreSQL、位置検索にPostGIS
- 認証：eKYC SDK連携、通知：FCM
- 地図：Mapbox / Google Maps

## MVP範囲
プロフィール登録 → 近所検索 → チャット → 予約 → レポート → 相互レビュー。
ポイントと保険は第2フェーズ、法人契約は第3フェーズ。
