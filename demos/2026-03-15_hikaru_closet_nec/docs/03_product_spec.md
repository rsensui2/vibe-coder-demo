# ひかるクローゼット - プロダクト仕様書

## 1. システムアーキテクチャ

### フロントエンド
- iOS（Swift/SwiftUI）: iOS 16以上対応
- Android（Kotlin/Jetpack Compose）: Android 10以上対応
- React Native（共通コンポーネント管理）

### バックエンド
- API Gateway: AWS API Gateway + Lambda
- 画像処理: Vision API（Google Cloud）+ カスタムAIモデル
- データストア: PostgreSQL（ユーザーデータ）+ S3（画像）
- 推薦エンジン: Python（FastAPI）+ TensorFlow Lite

### AI/MLパイプライン
- 服認識モデル: ResNet-50ベースのカスタムモデル（精度92%）
- コーデ推薦: Collaborative Filtering + Content-Based Hybrid
- バーチャル試着: DressCode（Diffusionベース仮想試着モデル）
- スタイル分析: CLIP（OpenAI）で色・素材・シルエット抽出

## 2. 主要機能仕様

### AIクローゼット管理
- 撮影→画像認識（2秒以内）
- 自動タグ付け: カテゴリ・色・素材・ブランド・価格帯
- 在庫管理: 着用回数・最終着用日・コスパ計算
- 季節別・シーン別フィルタリング

### パーソナルスタイリングAI
- 毎朝7時: 当日天気×予定×好み で3パターン提案
- 好みフィードバック学習（いいね・スキップで継続改善）
- 特別シーン対応（冠婚葬祭・ビジネス・デート等）

### バーチャル試着
- ユーザーの体型データ（身長・体重・体型タイプ）入力
- 服×体型を合成（DressCode AI）
- 前後左右360度プレビュー
- 実際の着用感コメント表示

### EC連携
- ZOZOTOWN・Amazon Fashion・楽天ファッションと連携
- 「このアイテムが欲しい」→ アプリ内購入
- 購入履歴とクローゼットの自動同期

## 3. プライバシー・セキュリティ
- 画像データはローカル処理優先（オンデバイスAI）
- クラウド送信時はエンドツーエンド暗号化
- GDPR/個人情報保護法完全準拠
- ユーザーデータの第三者提供はオプトイン制
