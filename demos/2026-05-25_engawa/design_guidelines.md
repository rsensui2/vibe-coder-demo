# Engawa — Design Guidelines

## Brand Essence
- Concept: 「縁側」— 内と外、私と公、静と動が自然に交わる場
- Tone: 温かい・静謐・誠実・余白・人肌の温度
- Audience: 70-90代シニア本人 + 家族世代 + 自治体/事業者
- Mood: 和モダン・木漏れ日・夕暮れの縁側・湯呑みの湯気

## Color Palette (Primary)
| Token | Hex | Use |
|-------|-----|-----|
| `--bg-cream` | `#FBF6EC` | 背景・余白・主要面 |
| `--bg-paper` | `#F2E9D8` | カード・セクション区切り |
| `--ink` | `#2A2620` | 本文・主要テキスト（純黒は避ける） |
| `--ink-soft` | `#5C5448` | サブテキスト・補足 |
| `--accent-engawa` | `#B5654A` | 主要アクセント（柿渋・夕暮れ） |
| `--accent-indigo` | `#27496D` | サブアクセント（藍） |
| `--accent-moss` | `#7A8B5C` | 強調・成功・自然 |
| `--accent-gold` | `#C9A75B` | 細部装飾・引用線 |

純黒・純白は使わない。彩度は中〜低。

## Typography
- 和文: Noto Serif JP / Shippori Mincho（明朝系）見出し、Noto Sans JP（本文）
- 欧文: Cormorant Garamond / Playfair Display（見出し）、Inter（本文）
- 本文は最低 17px、シニア向けLP/モックは 18-20px。行間 1.8〜2.0。

## Visual Motifs
- 縁側の板目（木目）— 細い線で示唆する
- 障子の格子・畳の縁・暖簾の揺れ
- 湯呑みから立ち上る湯気・夕陽の差し込み
- 紙のテクスチャ（淡い和紙）
- 線画イラスト（柔らかく、説明的でない）

## Forbidden
- ネオン色・蛍光色
- パーティクル・3D回転・派手なグラデ
- 若者向けポップなアイコン羅列
- 過剰なシャドウ・ボーダーラジアス（角は控えめに）
- AI生成感のあるフラットイラスト羅列

## Voice
- 「あなた」呼称、敬語ベース
- やわらかい体言止め、句読点を多めに
- 「孤独」「死別」を直接刺激しない言い換え（"離れていく友""ひとりの夕方"）
- 数字・効果を声高に煽らない。静かな確信。
