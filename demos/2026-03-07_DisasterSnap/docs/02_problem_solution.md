# DisasterSnap - 課題とソリューション詳細

## 課題の深掘り

### 1. 外国人観光客の災害時の現実
- 日本の緊急番号（119/110）は英語対応が限定的
- 2024年能登地震: 外国人観光客の安否確認に平均72時間
- 観光地（京都・大阪・富士山周辺）での外国人被災リスクが年々増加

### 2. 既存ツールの限界
- J-Alert: 日本語のみ、一方向通知
- 観光客向け防災アプリ: インストール率3%以下
- SNS: 情報が分散、信頼性検証困難

## DisasterSnapのソリューション

### コアテクノロジー
1. **Vision AI**: Google Vision API + 独自学習モデルで被害分類
2. **位置情報**: GPS + Wi-Fiポジショニングで精度10m以内
3. **翻訳エンジン**: DeepL API + 専門用語辞書（防災用語対応）
4. **ダッシュボード**: 自治体向けリアルタイムモニタリング

### 投稿フロー（観光客側）
```
QRコード読み取り（3秒）
→ カメラ起動（1タップ）
→ 写真撮影・位置情報自動付与（5秒）
→ 言語選択（母国語で説明追加、任意）
→ 送信完了（2秒）
合計: 約10秒
```

### 受信フロー（自治体側）
```
リアルタイムアラート受信
→ AI被害判定結果表示
→ 地図上で位置確認
→ 翻訳済み情報閲覧
→ 救助チーム派遣指示
```
