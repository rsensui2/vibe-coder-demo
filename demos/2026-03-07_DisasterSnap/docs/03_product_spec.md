# DisasterSnap - プロダクト仕様

## システム構成

### フロントエンド（観光客向け）
- **技術**: Progressive Web App（PWA）
- **対応言語**: 英語・中国語（簡/繁）・韓国語・スペイン語・フランス語・タイ語・ベトナム語・アラビア語・ポルトガル語・日本語
- **対応OS**: iOS 14+ / Android 10+
- **オフライン対応**: 電波なし環境でも写真保存→復帰時自動送信

### バックエンド
- **インフラ**: AWS（東京リージョン、大阪DR）
- **API**: REST + WebSocket（リアルタイム通知）
- **DB**: PostgreSQL（PostGIS拡張）+ Redis（キャッシュ）
- **ストレージ**: S3（写真）+ CloudFront（CDN）

### AI機能
| 機能 | モデル | 精度 |
|------|--------|------|
| 被害判定 | YOLOv8 + 独自ファインチューニング | 92% |
| 緊急度スコアリング | Random Forest | 89% |
| 翻訳品質チェック | GPT-4o | 96% |

## 自治体ダッシュボード
- リアルタイムマップ（被害ピン表示）
- アラート管理（未処理/対応中/完了）
- 統計レポート（時系列・地域別）
- 多機関連携（消防・警察・自衛隊との共有）

## QRコード配布
- 観光案内所・空港・主要観光地の案内板に設置
- ホテルのチェックインカードに印刷
- 訪日観光アプリとのAPI連携
