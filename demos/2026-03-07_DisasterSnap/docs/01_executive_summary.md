# DisasterSnap - エグゼクティブサマリー

## サービス概要
**DisasterSnap**は、日本を訪れる外国人観光客が災害発生時に写真1枚で状況を共有できる多言語対応プラットフォームです。AIが写真を解析し、被害状況・位置情報・優先度を自動判定。自治体・消防・観光案内所がリアルタイムで把握し、迅速な救助・避難誘導を実現します。

## 解決する課題
1. **言語の壁**: 外国人観光客は緊急時に日本語で状況を説明できない
2. **情報の分断**: SNS投稿は散乱し、救助機関が状況を把握できない
3. **位置情報の欠如**: 「どこで何が起きているか」がリアルタイムでわからない
4. **孤立リスク**: 観光地で被災した外国人が助けを求める手段がない

## ソリューション
- **ワンタップ投稿**: アプリ不要。カメラを開いてQRコードを読むだけ
- **AI被害判定**: 写真から被害レベル（軽微/中程度/重大）を自動判定
- **多言語自動翻訳**: 投稿内容を10言語に即時翻訳
- **リアルタイムマップ**: 被害報告が地図上に集約され、救助機関がアクセス可能
