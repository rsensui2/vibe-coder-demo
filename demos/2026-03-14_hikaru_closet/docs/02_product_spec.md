# ひかるクローゼット プロダクト仕様

## コア機能

### 1. スキャン＆マッチング
- カメラで服を撮影→色・形・スタイルをAIが解析
- 自分のクローゼット（登録済み服）と自動マッチング
- マッチング精度：色調・スタイル・季節感を総合判定

### 2. コーディネート提案
- 3パターン提案（カジュアル・きれいめ・トレンド）
- 各コーデのスコア表示（合わせやすさ100点満点）
- 「なぜこのコーデ？」のAI解説付き

### 3. クローゼット管理
- 服の写真を登録（最大10着 Free / 無制限 Premium）
- タグ付け（色・カテゴリ・ブランド・季節）
- 着用回数・最終着用日の自動記録

### 4. トレンド分析（Premium）
- 今季トレンドと自分のクローゼットのギャップ分析
- 「買い足すべき1着」の提案

### 5. 友達シェア（Premium）
- コーデを友達に送って意見をもらう
- 友達のクローゼットからコーデを借りる機能

## 技術スタック
- フロント: React Native（iOS/Android対応）
- AI: Vision API + GPT-4 Vision
- バックエンド: Node.js + Supabase
- 画像ストレージ: S3 + CloudFront
