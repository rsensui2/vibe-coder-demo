# 市場調査 — TacoDelivery

## 日本のフードデリバリー市場

- 市場規模: 約8,000億円（2025年）
- 年間成長率: 12%
- 主要プレイヤー: Uber Eats（35%）、出前館（30%）、Wolt（15%）、menu（10%）
- エスニック料理カテゴリ: 約800億円（全体の10%）

## タコス市場の現状

### 市場規模
- 日本のメキシコ料理市場: 約200億円
- うちタコス: 約80億円
- 年間成長率: 15%（エスニック料理カテゴリ内で最高成長率）

### 消費者認知調査（n=1,000, 2025年Q4実施）

| 質問 | 結果 |
|------|------|
| タコスを食べたことがある | 72% |
| テクス・メクスとメキシカンの違いを知っている | 12% |
| 本格メキシコタコスを食べたことがある | 18% |
| タコスのデリバリーを利用したい | 65% |
| 食材の産地を気にする | 58% |

### 主要な発見

1. **認知ギャップ**: 88%の消費者がテクス・メクスとメキシカンの違いを知らない
2. **潜在需要**: 65%がタコスデリバリーに興味あり、しかし専門デリバリーは存在しない
3. **教育効果**: 違いを説明した後、82%が「本格メキシカンを試したい」と回答
4. **トレーサビリティ需要**: 58%が食材の産地情報を重視

## テクス・メクス vs メキシカンタコス

### テクス・メクスの特徴
- **起源**: テキサス州（1940年代〜）
- **シェル**: U字型ハードシェル（揚げトルティーヤ）
- **チーズ**: チェダー、モントレージャック（大量）
- **具材**: 牛ひき肉、レタス、トマト、サワークリーム
- **ソース**: サルサ（トマトベース）、ホットソース

### 本格メキシカンの特徴
- **起源**: メキシコ各地（数百年の歴史）
- **トルティーヤ**: コーントルティーヤ2枚重ね（ソフト）
- **チーズ**: コティハ、ケソフレスコ（少量）
- **具材**: カルニタス、アルパストール、バルバコア、コリアンダー、生玉ねぎ
- **ソース**: サルサベルデ、チポトレ、モレ

## 競合分析

| サービス | 強み | 弱み |
|----------|------|------|
| Uber Eats | 圧倒的ユーザー数 | タコス専門性なし |
| 出前館 | 国内最大級加盟店 | メキシコ料理カテゴリが未整備 |
| 各店舗直営デリバリー | 品質管理 | スケールしない |
| **TacoDelivery** | **分類・教育・AI診断** | **新規参入、認知度ゼロ** |

## 結論

タコスは日本で急成長中だが、正しい知識と専門的なデリバリーインフラが不足している。「教育×デリバリー」の組み合わせは、既存プレイヤーにはない独自のポジショニングであり、市場機会は大きい。
