# Go-To-Market戦略 — TacoDelivery

## フェーズ別展開

### Phase 1: 東京都内ローンチ（0〜6ヶ月）

**エリア**: 渋谷・恵比寿・六本木・新宿（タコス店密集エリア）

**目標**:
- パートナー店舗30店
- 月間注文1,000件
- MAU 5,000人

**施策**:
- タコスフェスティバルでのブース出展・診断体験
- Instagram/TikTokでの「テクス・メクス vs メキシカン」教育コンテンツ
- フードインフルエンサー30名への無料体験提供
- 初回注文50%OFF + タコスパス1ヶ月無料キャンペーン

### Phase 2: 関東圏拡大（6〜12ヶ月）

**エリア**: 横浜・大宮・千葉・町田

**目標**:
- パートナー店舗100店
- 月間注文10,000件
- MAU 30,000人

**施策**:
- タコス診断AIリリース（パーソナライゼーション強化）
- 法人ケータリングサービス開始
- メディアPR（日経MJ、TechCrunch Japan）
- リファラルプログラム（友達紹介で双方500円OFF）

### Phase 3: 全国展開（1〜2年）

**エリア**: 大阪・名古屋・福岡・札幌

**目標**:
- パートナー店舗500店
- 月間注文50,000件
- MAU 150,000人

**施策**:
- ライブキッチン機能全店展開
- 自社PBブランド「TacoDeli Original」ローンチ
- 文化コラム週刊配信（タコスの歴史・地域差・食べ方）
- サブスク会員限定イベント（メキシコ人シェフのオンライン料理教室）

## ターゲットユーザー

| セグメント | 年齢 | 特徴 | アプローチ |
|-----------|------|------|-----------|
| フーディー層 | 25-35 | SNS発信、新しい味に敏感 | Instagram/TikTok |
| ヘルシー志向層 | 30-45 | 原材料・産地にこだわる | トレーサビリティ訴求 |
| 法人 | - | ランチ・懇親会需要 | 法人営業・ケータリング |

## 競合優位性

1. **唯一の分類型タコスデリバリー**: テクス・メクスとメキシカンを明確に区別する唯一のサービス
2. **教育×デリバリー**: 食べるだけでなく「知る」体験を提供
3. **AI診断**: パーソナライズされたメニュー提案で離脱率低下
4. **ライブキッチン**: 調理の可視化で信頼性向上、リピート率68%の原動力
