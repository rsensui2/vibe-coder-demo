# プロダクト仕様書 — TacoDelivery

## コア機能

### 1. タコス診断AI

- **概要**: 5問の味覚クイズでユーザーの好みプロファイルを生成
- **質問例**:
  - 「辛さの好みは？」（マイルド〜激辛）
  - 「チーズは多め？少なめ？」
  - 「トルティーヤはハード？ソフト？」
  - 「好きな具材は？」（肉/魚介/野菜）
  - 「ソースの好みは？」（サルサ/ワカモレ/サワークリーム）
- **出力**: テクス・メクス度 vs メキシカン度のスコア + おすすめメニュー3品
- **技術**: 味覚プロファイリングML モデル、ユーザー行動データでの継続学習

### 2. カテゴリ分類メニュー

- 全メニューに「テクス・メクス」「メキシカン」バッジを表示
- フィルタリング・ソート機能
- 各メニューに「これがテクス・メクスである理由」の教育コンテンツ付き

### 3. 産地トレーサビリティ

- トルティーヤ: 使用粉の産地（オアハカ州、ソノラ州 etc.）
- 唐辛子: 品種（ハラペーニョ、セラーノ、ハバネロ etc.）と産地
- 肉: 調理法（アルパストール、カルニタス、バルバコア etc.）の解説

### 4. ライブキッチン

- パートナー店舗にカメラ設置（初期費用当社負担）
- 注文後、調理開始〜完成までリアルタイム配信
- アーカイブ機能で過去の調理動画も閲覧可能

## 技術スタック

| レイヤー | 技術 |
|----------|------|
| フロントエンド | React Native (iOS/Android) |
| バックエンド | Node.js + Express |
| データベース | PostgreSQL + Redis |
| AI/ML | Python + TensorFlow |
| 配信 | WebRTC (ライブキッチン) |
| インフラ | AWS (ECS + RDS + CloudFront) |

## 非機能要件

- レスポンスタイム: 画面遷移1秒以内
- 同時接続: 10,000ユーザー対応
- 稼働率: 99.9%
- ライブ配信遅延: 3秒以内
