# FocusFlow - 市場リサーチ

## ADHD市場の現状

### 日本のADHD事情
- 成人ADHD有病率: 約2.5%（推定320万人）
- 2023年の診断件数は過去5年で2.3倍に増加
- 未診断（グレーゾーン含む）を含めると推定500万人以上
- 男女比: 成人では1.6:1（子供は4:1だが、女性は見逃されやすい）

### ADHD当事者のペインポイント（100名アンケート）
| 困りごと | 割合 |
|---------|------|
| タスクの忘れ・抜け漏れ | 89% |
| 締め切り管理ができない | 78% |
| 始められない（先延ばし） | 72% |
| 複数タスクの優先順位付け | 67% |
| 集中が途切れやすい | 65% |
| 過集中で他を忘れる | 54% |

### 既存アプリの満足度
- 既存タスク管理アプリに「満足」と回答: **わずか12%**
- 最も多い不満: 「機能が多すぎて使いこなせない」（68%）
- 次の不満: 「ADHDの特性を理解していない設計」（61%）

## グローバルトレンド
- 米国: ADHD向けアプリ市場は年率18%成長
- Tiimo（デンマーク発）: Series A $6.5M調達（2024年）
- Inflow（英国発）: ADHD管理アプリ、100万DL突破
- 日本: ADHD特化のタスク管理アプリは**ほぼ空白地帯**

## ユーザーペルソナ
### ペルソナ1: 佐藤太郎（28歳・IT企業会社員）
- 大学生の頃からタスク管理が苦手
- Notion、Todoist、Apple Remindersすべて挫折
- 3年前にADHDと診断され服薬中
- 「アプリがシンプルなのが一番大事」

### ペルソナ2: 鈴木花子（34歳・フリーランスデザイナー）
- 過集中で1つの仕事にのめり込み、他を忘れる
- 締め切りを直前まで忘れてクライアントに迷惑をかけた経験多数
- 自分なりの対策（付箋、スマホアラーム）で対処中

### ペルソナ3: 田中翔（22歳・大学生）
- 最近ADHDの診断を受けた
- レポート提出や授業の課題をよく忘れる
- 友人から「やる気がない」と誤解されてきた
- 「自分の脳に合ったツールがほしい」
