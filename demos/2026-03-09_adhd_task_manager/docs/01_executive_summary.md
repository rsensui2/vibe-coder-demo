# FocusFlow - エグゼクティブサマリー

## サービス概要
**FocusFlow**は、ADHD（注意欠如・多動性障害）の特性を持つ人のために、神経科学と行動心理学をベースに設計されたタスク管理アプリケーションです。

## 解決する課題
日本のADHD人口は推定320万人。その7割以上がタスク管理に深刻な困難を抱えています。既存のTo-Doアプリは定型発達の人向けに設計されており、ADHD脳の特性（ワーキングメモリの弱さ、時間盲、実行機能障害、報酬系の感受性の違い）を考慮していません。

## ソリューション
FocusFlowは5つの革新的機能で上記の課題を解決します：
1. **1タスク集中モード** - 今やるべき1つだけを表示し、注意散漫を構造的に排除
2. **タイムプレッシャービジュアライザー** - 砂時計UIで時間盲を視覚的に補完
3. **報酬ドーパミンシステム** - タスク完了時に強力な達成感演出でモチベーション維持
4. **AI割り込みブロッカー** - 集中中の通知をAI自動分類・ブロック
5. **体感時間カレンダー** - ADHD特有の時間感覚に合わせた直感的UI
