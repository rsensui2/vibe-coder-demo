# FocusFlow - プロダクトデザイン仕様書

## デザイン哲学
「1画面1情報」の原則。ADHD脳は情報過多に弱い。すべてのUIは認知負荷の最小化を最優先に設計する。

## カラーパレット
- **ダークモード（デフォルト）**: ディープネイビー(#0D0D1A) × バイオレット(#7B61FF) × サイアン(#00D4FF)
- 目の疲れに配慮し、ダークモードを標準搭載

## 主要画面設計

### 1. 集中モード画面
- 全画面に「今やるべきタスク」1つだけを表示
- 大きなカウントダウンタイマー（バイオレット→サイアンのグラデーション）
- プログレスバーで進捗を視覚化
- 「完了」ボタンは常に最も目立つ位置に配置

### 2. タスク一覧画面
- 優先度別の色分け（高:赤/中:橙/低:サイアン）
- 完了タスクはストライクスルー表示で達成感を強調
- 本日のスタッツ（残り/完了/ストリーク）を上部に固定

### 3. タイマー画面（タイムプレッシャービジュアライザー）
- 巨大な円形タイマー（砂時計メタファー）
- 残り時間が少なくなるにつれバイオレット→赤に変色
- 直感的に「急がなきゃ」と感じられるUI

### 4. 報酬画面
- タスク完了時に自動遷移
- コンフェッティアニメーション + 効果音
- バッジ獲得、連続日数、今日の完了数を一覧表示

### 5. 設定画面
- AI割り込みブロッカーのON/OFF
- 完了エフェクト（サウンド/コンフェッティ）の切り替え
- 外部サービス連携（Googleカレンダー、Slack）

## レスポンシブ対応
- iOS / Android ネイティブ（React Native）
- Web版（Progressive Web App）
- 全デバイスでデータ同期
