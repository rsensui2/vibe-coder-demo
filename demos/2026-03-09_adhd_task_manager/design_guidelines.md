# FocusFlow デザインガイドライン

## プロジェクト概要
**FocusFlow** - ADHDの人が「タスクを忘れない」「先延ばししない」ためのタスク管理アプリ

## ターゲットユーザー
- ADHDと診断された、または疑いがある20〜40代のビジネスパーソン・学生
- 「やろうと思ってたのに忘れた」「集中できない」「複数タスクで混乱する」に悩む人

## サービス特徴
1. **タイムプレッシャービジュアライザー** - 締め切りまでの時間をリアルタイムで視覚化（砂時計アニメーション）
2. **1タスク集中モード** - 今やるべき1つだけを全画面表示、他は隠す
3. **報酬ドーパミンシステム** - タスク完了時に強い達成感演出（コンフェッティ＋サウンド）
4. **AI割り込みブロッカー** - 作業中の通知を自動分類・ブロック
5. **体感時間カレンダー** - ADHD特有の「時間盲」を補う直感的タイムライン

## デザイン方針
- ダークモード中心（ADHDユーザーは目の疲れに敏感）
- アニメーションは意図的・機能的（気が散るような装飾は排除）
- 1画面1情報の原則（認知負荷を最小化）
- ネオン発光エフェクト（バイオレット×サイアン）でフォーカス感を演出
- 余白を大きく取り、情報密度を下げる
