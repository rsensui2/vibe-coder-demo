# AI Agent Dispatch - 市場調査

## 市場規模とトレンド

### グローバルAIエージェント市場
- 2025年：52億ドル
- 2030年予測：280億ドル（CAGR 40%）
- 日本市場：2025年1,200億円 → 2030年5,800億円

### 労働市場の構造的課題
- 少子高齢化による労働力人口減少（年間50万人ペース）
- DX投資額：2025年度5.2兆円（前年比18%増）
- リモートワーク定着による業務デジタル化の加速

## 競合分析

### 直接競合
| 企業 | 強み | 弱み | 料金 |
|------|------|------|------|
| AutoGPT Enterprise | 技術力 | UI/UX未熟 | 月10万円〜 |
| AgentForce (Salesforce) | CRM統合 | Salesforce依存 | 月20万円〜 |
| CrewAI Pro | オープンソース実績 | 企業向け機能不足 | 月8万円〜 |

### 間接競合
- RPAベンダー（UiPath, Automation Anywhere）
- チャットボット（Zendesk, Intercom）
- 人材派遣・BPO（パーソル、テンプホールディングス）

### 我々の差別化
1. **即日稼働** — 競合は導入に1〜3ヶ月
2. **カスタム学習** — 顧客の業務フローをそのまま再現
3. **日本特化** — 日本語ネイティブ・日本のビジネス慣行に対応
4. **低価格** — 人材派遣の1/10、競合の1/2

## ユーザーインサイト（インタビュー結果）

### 営業部門（n=15）
- 「商談前調査に1日2時間かかる」— 87%
- 「AIで自動化したいが、設定が難しい」— 73%
- 「月5万なら即導入」— 80%

### CS部門（n=12）
- 「夜間問い合わせへの対応が課題」— 92%
- 「解約防止に使いたい」— 67%
- 「トライアルで試したい」— 85%

### 経理部門（n=8）
- 「月末は毎月地獄」— 100%
- 「入力ミスが0になれば導入したい」— 88%
