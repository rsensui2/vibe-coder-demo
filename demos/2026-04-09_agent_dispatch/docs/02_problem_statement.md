# AI Agent Dispatch - 課題定義

## 日本の労働市場の現実

### 人手不足の深刻化
- 2025年の労働力人口：6,074万人
- 2030年予測：5,620万人（450万人減少）
- 有効求人倍率：1.33倍（2025年）
- 中小企業の71%が「人手不足」

### DX人材の不足
- 79%の企業がDX人材不足と回答
- AIエンジニアの平均年収：800万円（市場の3倍）
- 採用期間：平均3〜6ヶ月
- 内定辞退率：42%

### 定型業務の非効率性
- 営業担当者の業務時間の65%が非営業活動
- カスタマーサポートの夜間対応率：12%
- 経理部門のデータ入力工数：月平均120時間
- 人材紹介手数料：年収の30〜35%

## 既存ソリューションの限界

### RPA
- 固定ルールのみ・例外対応不可
- 導入に3〜6ヶ月
- メンテナンスコストが年々増加

### チャットボット
- 事前定義のQ&Aのみ
- 複雑な業務は対応不可
- 顧客満足度：平均32%

### 人材派遣
- 月50〜80万円（社会保険込）
- 即日稼働不可能
- 定着率に課題
