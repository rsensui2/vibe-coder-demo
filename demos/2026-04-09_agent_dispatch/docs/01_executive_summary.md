# AI Agent Dispatch - エグゼクティブサマリー

## ビジョン
「自分を、派遣する。」
AIエージェント派遣事業は、人間の業務を理解したAIワーカーを企業に派遣する新しい働き方の形です。

## 市場規模
- 日本のAIエージェント市場：2025年1,200億円 → 2030年5,800億円（CAGR 37%）
- 労働力不足：2030年までに450万人減少
- DX人材不足：79%の企業が回答

## ソリューション
AIエージェントが人間の分身として24時間365日稼働。営業支援・カスタマーサクセス・バックオフィスの定型業務を代行。

## 競合優位性
1. **即日稼働** - ヒアリング1時間、設定5分で業務開始
2. **低コスト** - 月5万円〜（人材派遣の1/10）
3. **カスタマイズ** - 顧客ごとに業務フローを学習
4. **スケーラブル** - 必要な時に必要なだけ追加

## 収益モデル
- Starter: 月5万円（1エージェント）
- Professional: 月15万円（3エージェント + 優先サポート）
- Enterprise: 月50万円〜（カスタム構成 + 専任コンサルタント）

## ターゲット
- 中小企業の営業部門（商談前調査の自動化）
- カスタマーサクセス部門（24時間対応）
- バックオフィス（経理・データ入力の自動化）
