# Design Guidelines: メキシカンタコスのデリバリーサービス

## Brand
- Tagline: 焼きたてのメキシコを、玄関まで。
- Tone: 明るく食欲を刺激する、カラフル、スパイス感。ただし安っぽくしない。
- Audience: 都市部の20〜40代、オフィスランチ需要、ホームパーティー需要、辛いもの好き、Uber Eats疲れしたグルメ層

## Visual System
- Main colors: tortilla gold #FFD166, salsa red #E63946, avocado green #2F9E44, night charcoal #1E1B18
- Accent colors: lime #C7F464, crema #FFF3D4, chili orange #F77F00
- Typography: 太めの日本語見出し、読みやすい本文、余白は広く。
- Texture: 焼き目、紙包み、手書き風ライン、サルサの点描。

## UI Direction
- LP Pattern 1: カラフルで都市的、ランチ注文に強い即時性。
- LP Pattern 2: プレミアムで上質、本格メキシコ感と素材訴求。
- LP Pattern 3: 深夜・パーティー需要に寄せたポップなスパイス感。
