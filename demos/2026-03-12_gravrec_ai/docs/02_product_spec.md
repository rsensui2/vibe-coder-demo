# GravRec AI - プロダクト仕様書

## コア機能

### 1. リアルタイム音声解析
- ブラウザのマイク権限で音声取得
- Speech-to-Text API（日本語特化）でリアルタイム文字起こし
- 話者分離（複数人の会話を識別）
- キーワード・概念抽出AIで重要要素を特定

### 2. グラレコ自動生成
- 抽出した概念を視覚的要素（ノード・矢印・アイコン）にマッピング
- 手書き風SVGスタイルで生成（温かみのあるビジュアル）
- 会話の流れに沿って左から右へレイアウト
- カテゴリ別カラーコーディング（課題=赤、解決策=青、アクション=緑）

### 3. インタラクティブ確認
- 「こんな感じですか？」ボタンで生成グラレコを画面共有
- リアルタイムフィードバックで修正可能
- 参加者がコメント・マーク追加可能

### 4. PDF書き出し・共有
- 会議終了後に一クリックでPDF出力
- タイムスタンプ付きの会話ログ同梱
- 共有リンク生成（24時間有効）

## 技術スタック
- フロントエンド: React + TypeScript
- 音声処理: Web Speech API + Whisper API（フォールバック）
- AI生成: Claude API（概念抽出・構造化）
- グラフィック: SVG.js（手書き風描画）
- バックエンド: Node.js + Supabase
- 認証: Clerk

## 対応環境
- ブラウザ: Chrome 90+、Edge 90+、Safari 15+
- OS: Windows、macOS、Linux（ブラウザのみ）
- 推奨帯域: 1Mbps以上
