# GravRec AI - GTM戦略

## ローンチ戦略

### Phase 1: ベータ期（0〜3ヶ月）
- ターゲット: コンサルタント・ファシリテーター（早期採用者）
- チャネル: Producthunt、Twitterバイラル、LinkedIn
- 目標: 1,000 MAU達成
- 施策: 招待制ベータ → 口コミ拡散

### Phase 2: グロース期（3〜12ヶ月）
- ターゲット: SaaS企業・外資系企業の営業/CS部門
- チャネル: B2Bコンテンツマーケティング、ウェビナー
- 目標: Pro有料転換率15%達成
- 施策: 「会議の質を変えた事例」コンテンツ量産

### Phase 3: エンタープライズ期（12ヶ月〜）
- ターゲット: 従業員1,000人以上の大手企業IT部門
- チャネル: 代理店・ISV連携、Zoom/Teams Marketplace
- 目標: ARR 1億円突破
- 施策: エンタープライズセキュリティ対応・SSO実装

## 価格設定根拠
- Free: 体験ハードルを下げる。口コミ獲得が目的
- Pro（¥1,980）: 月2〜3回の会議で元が取れる価格設定
- Team（¥4,980）: 1人あたり¥996で企業導入しやすい価格
