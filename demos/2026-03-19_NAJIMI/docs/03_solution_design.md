# NAJIMI - ソリューション設計書

## システムアーキテクチャ

```
[来店客] → [入口カメラ] → [顔認識AI] → [顧客DB]
                                            ↓
                              [スタッフタブレット通知]
                                            ↓
                              「鈴木様、10回目のご来店です」
                              「いつもの穴子丼でよろしいですか？」
```

## コア機能

### 1. リアルタイム顔認識ウェルカム
- 精度: 99.9%（登録顧客に対して）
- 処理速度: 入店から0.3秒以内
- プライバシー: 顔データはオンプレ処理（施設外に出ない）

### 2. 嗜好学習メモリー
- 注文履歴の自動記録
- 好みの席・時間帯の学習
- 誕生日・記念日の管理
- 苦手な食材・アレルギー情報

### 3. クロスストア常連システム
- 同一ビル内の複数店舗で常連情報を共有
- 来店頻度に応じた「常連度」スコア管理
- 各店舗が独自のサービスルールを設定可能

## 技術スタック

- 顔認識: AWS Rekognition / Azure Face API
- バックエンド: Node.js + PostgreSQL
- スタッフアプリ: React Native（iOS/Android）
- セキュリティ: ゼロトラスト、E2E暗号化

## プライバシー対策

GDPR・個人情報保護法に準拠。顧客は登録・削除を自由に制御できます。
