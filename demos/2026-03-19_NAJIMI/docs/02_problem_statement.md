# NAJIMI - 課題定義書

## 背景：大型商業施設が抱える「常連断絶問題」

### 1. アルバイト離職率の深刻化

国内飲食・小売業のアルバイト離職率は年間40〜60%に達しています。
これは、スタッフが年に半数入れ替わることを意味し、**顧客の「馴染み」がリセット**されます。

### 2. 顧客の疎外感

ユーザーインタビューから得られた声：
- 「10回通っても名前すら覚えてもらえない」
- 「好きなメニューを毎回説明するのが面倒」
- 「顔を覚えてもらえると嬉しいのに、アルバイトがすぐ変わる」

### 3. 店舗間の情報サイロ化

同一ビル内に複数テナントがあっても、顧客情報は各店舗に閉じています。
金子半之助で常連でも、隣のカフェでは「はじめてのお客様」です。

## 課題の定量化

| 指標 | 現状 |
|------|------|
| アルバイト平均勤続期間 | 6〜8ヶ月 |
| 顧客の再訪問率（大型SC） | 32% |
| CX不満による離脱率 | 年間18% |
| リピーター1人あたりLTV | 新規の5〜7倍 |

## NAJIMIが解決するもの

テクノロジーで「スタッフの記憶」を代替・拡張し、誰が対応しても一貫した常連体験を提供します。
