# TaxPilot プロダクトコンセプト

## コンセプトの核心

> **「確定申告を、呼吸するように簡単に。」**

TaxPilotのコンセプトは、確定申告という「年に一度の面倒な作業」を「当たり前の日常習慣」に変えることです。AIを使えば、レシートを撮るたびに自動で経費が記録され、年末になったら申告書がほぼ完成している状態を作れます。

## UXデザイン哲学

### 1. ゼロ入力の追求
確定申告で一番ストレスなのは「入力作業」です。TaxPilotはあらゆる入力をなくすことを設計原則にしています。

- レシート → カメラで撮るだけ（AIが読み取る）
- 収支 → 口座連携で自動取得
- 申告書 → AIが自動作成
- 提出 → e-Taxにワンクリック

### 2. 不安を取り除く設計
確定申告には「これで本当に合ってる？」という不安がつきもの。TaxPilotは以下で解消します。

- **確認ステップ**: AIが生成した内容をわかりやすく表示し、ユーザーが最終確認できる
- **AIチャット**: 疑問が出たらすぐに税理士レベルの回答が得られる
- **エラー検知**: 申告書の矛盾・ミスをAIが事前にチェック

### 3. 継続利用を促すハビット設計
- 週次リマインダー（「先週のレシートをスキャンしましょう」）
- 経費ダッシュボード（いつでも今年の収支が一目でわかる）
- 還付予測額の表示（「このまま申告すると約X万円還付されます」）

## 技術スタック（概要）

| レイヤー | 技術 |
|---------|------|
| フロントエンド | React Native（iOS/Android共通）, Next.js（Web） |
| バックエンド | Node.js + Fastify, PostgreSQL |
| AI/ML | GPT-4o（申告書生成・チャット）, Cloud Vision API（OCR） |
| 金融連携 | Plaid（米）/ Open Banking API（日本） |
| e-Tax連携 | 国税庁 e-Tax API |
| インフラ | AWS（ECS + RDS + S3） |
