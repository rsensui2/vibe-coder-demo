# TaxPilot エグゼクティブサマリー

## サービス概要

**TaxPilot（タックスパイロット）** は、フリーランス・副業サラリーマン・個人事業主が確定申告を自力で完結できる、AIファーストの確定申告支援サービスです。

キャッチコピー：**「撮って、連携して、おわり。」**

---

## 解決する課題

日本のフリーランス・副業人口は2024年時点で約2,000万人を超えています。しかしその多くが毎年確定申告に苦労しており、以下の3つの問題が深刻です。

1. **時間コスト** — 確定申告にかかる平均時間は17.3時間（弊社調査）
2. **知識の壁** — 何を経費にできるか、どこに何を書くべきかがわからない
3. **費用** — 税理士に依頼すると年間3〜10万円かかる

TaxPilotはこれらをAIとシンプルなUXで解決します。

---

## ソリューション

### コア機能
1. **スマートレシートスキャン** — スマホのカメラで撮影するだけで、AI（OCR+LLM）が金額・日付・カテゴリを自動認識。精度99.2%。
2. **金融機関一括連携** — メガバンク・地銀・ネット銀行・クレジットカード1,000社超と連携。リアルタイムで収支を自動集計。
3. **AI申告書自動作成** — 所得税・消費税・住民税の申告書を自動生成。e-Tax形式（XML）で出力。
4. **AIチャットサポート** — 「この領収書は経費になる？」「白色申告と青色申告どっちがいい？」に即答。

### 利用フロー
```
スマホでレシート撮影 → 口座・カード連携 → AIが申告書作成 → e-Taxで提出完了
（最短5分で完了）
```
