# TaxPilot Go-to-Market戦略

## ローンチ戦略

### フェーズ1: クローズドβ（2026年1月〜2月）
- 対象: フリーランス協会会員・クラウドワークス登録者 500名
- 目標: NPS 50以上を確認、主要バグの修正
- 特典: 永久Freeアカウント + フィードバック謝礼

### フェーズ2: オープンβ（2026年3月 ← 確定申告シーズンに合わせる）
- 対象: 全ユーザー
- 「今年の確定申告は無料でTaxPilotで」キャンペーン
- 目標: 10,000ダウンロード・1,000有料転換

### フェーズ3: 本格展開（2026年4月〜）
- 広告・PR・パートナーシップ全開
- 目標: 月次1,000人有料ユーザー獲得

## 獲得チャネル

### 1. SEO/コンテンツマーケティング（最重要）
確定申告は強い検索意図を持つキーワードが多い。

**狙うキーワード**:
- 「確定申告 やり方 フリーランス」（月間検索数 120,000）
- 「確定申告 アプリ」（月間検索数 90,000）
- 「経費 仕分け 自動」（月間検索数 40,000）
- 「e-Tax 使い方」（月間検索数 80,000）

コンテンツ: 「確定申告完全ガイド2026」「経費になるもの・ならないもの一覧」

### 2. SNS広告（Facebook/Instagram）
- ターゲット: 35-50歳・フリーランス・副業キーワード
- CPAターゲット: ¥1,500/インストール → ¥3,000/有料転換

### 3. アフィリエイト・レビューサイト
- AppStoreフィーチャー獲得を目指す
- ITmedia・マイナビ・日経ビジネス等でのレビュー記事

### 4. パートナーシップ
- **クラウドワークス・ランサーズ**: フリーランス向け公認ツールとして掲載
- **会計事務所**: 税理士向けホワイトラベル提供（後続フェーズ）
- **freee・マネーフォワード**: データエクスポート連携

## 価格戦略

### フリーミアムモデル採用の理由
1. 確定申告は「使ってみないと良さがわからない」体験型サービス
2. まず無料で使ってもらい、申告シーズンに有料転換を促す
3. 口コミ効果（「無料で使えるよ」）

### 転換促進施策
- 無料プランで月5件の制限 → 使い込むほどProが必要になる設計
- 確定申告シーズン（2〜3月）に「今年は無料で試せます」訴求
- e-Tax出力はPro限定 → 最後の一歩でPro転換を促す
