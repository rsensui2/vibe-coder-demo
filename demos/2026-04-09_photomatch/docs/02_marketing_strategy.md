# Photomatch - マーケティング戦略

## ターゲットセグメント

### 優先順位1: フリーカメラマン（35-55歳）
- 商品撮影経験あり、年収 300-800万円
- Instagram/SNSで自分の作品を公開
- 「安定した顧客」「単価UP」に関心高い
- **獲得チャネル**: Instagram、photography系コミュニティ、YouTube、note

### 優先順位2: EC事業者（副業含む）
- Amazon/楽天/自社ECを運営
- 月商 100万円以上
- 商品撮影外注の必要性を感じている
- **獲得チャネル**: EC関連メルマガ、SEO、業界イベント

### 優先順位3: フォトスタジオ・撮影代行サービス
- マッチング通じた案件仲介
- **獲得チャネル**: B2B営業、業界誌

## マーケティングファネル

```
AWARENESS (認知)

  ↓ 
INTEREST (興味)

  ↓

```

## 認知フェーズ戦略（Month 1-2）

### 1. Instagram コンテンツマーケティング
- 投稿: 「良い写真 vs 良くない写真」比較、ライティングTips、撮影トレンド
- 頻度: 3-4回/週
- ハッシュタグ: #フリーカメラマン #商品撮影 #EC撮影 #カメラマン求人
- リール: 30秒の撮影技法Tips（再生数狙い）

### 2. YouTube チャンネル立ち上げ
- 動画企画:
  - 「初心者カメラマンの平均年収」
  - 「EC写真で稼ぐコツ」
  - インタビュー: 成功カメラマン
- 頻度: 2-3本/月
- CTA: Photomatchへのリンク（概要欄）

### 3. note 記事シリーズ
- 記事例:
  - 「フリーカメラマンが紹介から脱する方法」
  - 「EC事業者が理想のカメラマンを見つける方法」
- 頻度: 週1
- CTA: メルマガ登録 + Photomatch登録リンク

### 4. メディア露出
- TechCrunch / Startup DB / ITmedia への記事化
- 業界誌「カメラジャーナル」「写真ビジネスニュース」への投稿

## 興味 → 登録フェーズ（Month 3）

### 1. ランディングページ最適化
- A/B テスト: 見出し3パターン
  - Pattern 1: 「あなたの作品が、必要とされる場所へ」（感情訴求）
  - Pattern 2: 「商品撮影で月 +50万円」（数字訴求）
  - Pattern 3: 「EC事業者に直接提案できるプラットフォーム」（機能訴求）
- 申し込みハードル: 5分以内（メール + SNS ログイン）

### 2. メールマーケティング
- ウェルカムシーケンス: 5通 / 3週間
  - Day 1: ようこそ + ポートフォリオアップのやり方
  - Day 3: 成功事例（カメラマン 実名）
  - Day 7: プラットフォーム機能ツアー
  - Day 14: 初マッチングまでのロードマップ
  - Day 21: 限定オファー「初登録ボーナス 2ヶ月無料」

### 3. リファーラルプログラム
- 既存ユーザーが友人紹介: 手数料 500円キャッシュバック
- SNS シェアボーナス: 新規登録ユーザーがInstagramで紹介投稿 → 1000円プレゼント

## アクティベーション → 継続フェーズ（Month 4+）

### 1. コミュニティ構築
- Discord / Slack コミュニティ: 撮影テク情報交換、案件相談
- 月1 オンラインセミナー: 「成約率UP術」「相場設定の裏側」
- 四半期ごと「Photomatch Award」: 優秀カメラマン・優秀EC事業者を表彰

### 2. ナーチャリング
- 定期レポート: 「今月のトレンド撮影」「マッチング業界ニュース」
- ホワイトペーパー: 「EC撮影市場2026年レポート」無料DL

### 3. プレミアム機能推進
- 月額 1000円: 「バッジ表示」「検索上位表示」「直接スカウト受信」
- LTV (Lifetime Value) 目標: ユーザーあたり年額 5000-10000円
