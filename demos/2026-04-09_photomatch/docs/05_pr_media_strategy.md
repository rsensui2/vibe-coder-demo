## PR スケジュール

### Pre-Launch（Month -2 to -1）
**Goal**: メディア・インフルエンサーへの認知構築

- **Week 1-2**: メディアの記者・編集者へピッチメール
  - 件数: Tier 1 → 15-20件、Tier 2 → 30件
  - 文体: 「新しい市場機会」「市場規模 XYZ円」スタイル
  
- **Week 3**: フリーランスインフルエンサー（フォロワー10K+）へのギフト / 体験案内
  - リスト作成: Twitter フリーランス関連 KOL 30人
  - メッセージ: "Photomatch β版をあなたが最初に試してみませんか？"
  
- **Week 4**: プレスリリース準備
  - 配信: PR TIMES, 時事通信, Japan News Network など

### Launch Period（Month 0-1）
**Goal**: メディア掲載・SNS話題化

- **Day 0**: プレスリリース配信 + SNS一斉投稿
  - LP 公開 + 初期ユーザー募集告知
  - Twitter: CEO による深掘り 3-4tweet スレッド
  - Instagram: ビジュアルベフォー/アフター（紹介 vs デジタル）
  
- **Week 1**: メディアインタビュー（Tier 1-2）
  - 掲載ターゲット: 3-5件（TechCrunch 1、日経 1 など）
  
- **Week 2**: ユーザーストーリー公開
  - note 記事: "Photomatchで月収 50万 UP した実例"（実名カメラマン取材）
  - 想定 reach: 10K PV
  
- **Week 3**: YouTuber 配信予定
  - テックユーチューバー（50K+ 登録者）による紹介ビデオ
  - 想定 reach: 100K+ views

### Post-Launch（Month 2-6）
**Goal**: 継続的な話題化・シリーズ報道

| Month | ネタ | 媒体 |
|--------|------|------|
| Month 2 | "初マッチング達成 50件突破" | Twitter trending, Business Insider |

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【プレスリリース】

マッチングプラットフォーム「Photomatch」β版公開

「紹介から発見へ」— 5000人のカメラマンが、5万社のEC事業者から仕事を得られる世界

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【基本情報】
- サービス名: Photomatch
- 公開日: 2026年6月1日
- 形態: Web / iOS / Android
- 対象地域: 日本（初期）

【サービス概要】
Photomatchは、フリーランスカメラマンの「安定した仕事取得」と、
EC事業者の「信頼できるカメラマン発見」を同時に解決する
デジタルマッチングプラットフォームです。

従来の「紹介ベース」から「データドリブン」へ。
ポートフォリオを公開 → 需要側から発見される仕組みで、
月収UP・ビジネス拡大の新しい形を実現します。

【市場背景】
- 日本のフリーカメラマン数: 約8-10万人
  → 営業ネットワーク不足で仕事機会 60% 未活用
- EC市場年成長率: 12-15%
  → 商品撮影外注市場: 推定 300-500億円/年
  → Photomatch対象市場: 初年度 5-10億円の機会

【差別化ポイント】
1. EC撮影に特化 → 検索性・マッチング精度が高い
2. プロ品質保証 → ポートフォリオレビュー + スター制度
3. シンプル設計 → 登録〜依頼 3ステップ
4. 透明な相場 → カメラマンと事業者の情報非対称を解消

【提供機能】
- Photographer Dashboard: ポートフォリオ管理 + マッチング通知 + 収益管理
- EC Buyer Search: 詳細検索 + ワンクリック依頼 + チャット機能
- スター制度: 納期遵守・品質 + コミュニケーション評価の可視化
- Premium 機能: 目立たせ機能・直接スカウト受信（月額 1000円）
- Stripe 決済: 安全な 3者決済 + 週1自動払い

【ロードマップ】
- Month 1-3: MVP公開 + β テスト（初期ユーザー 100人）
- Month 4-6: 正式ローンチ（目標 5000 ユーザー）
- Month 7-12: Series A 資金調達 + 機能拡張
```
