# EquiLog — プロダクト仕様

## コア機能

### 1. PDF成績表取込み
- 試合結果PDFをドラッグ＆ドロップまたはカメラ撮影で取込み
- OCR + AIパーシングで馬名・選手名・タイム・減点・順位を自動抽出
- 手動補正UI付き

### 2. 馬プロフィール
- 馬名、性別、生年月日、品種、オーナー情報
- 生涯戦績サマリー（出場回数、入賞回数、平均順位、ベストタイム）
- 写真ギャラリー・動画アーカイブ
- 試合タイムライン（時系列で全出場記録を表示）

### 3. 試合記録
- 大会名、日付、会場、種目、コース情報
- 全出場馬・選手の成績一覧
- 自分の馬の成績ハイライト
- 天候・馬場状態メモ

### 4. 競合追跡
- 特定の馬・選手をウォッチリストに追加
- 過去の対戦履歴を自動集計
- 「この馬と前回対戦したのはいつ？」を即検索

### 5. メディア紐付け
- 写真・動画を試合・馬に紐付けて保存
- 走行動画のタイムスタンプ付きブックマーク
- 外部リンク（YouTube等）の登録にも対応

## 技術スタック
- フロントエンド: Next.js + React
- バックエンド: Supabase（PostgreSQL + Auth + Storage）
- OCR: Google Cloud Vision API
- モバイル: PWA（将来的にReact Native）
