# PupWhisper — プロダクト仕様

## コア機能

### 1. 感情翻訳（録音）
- スマホのカメラ＋マイクで犬の様子を30秒記録
- AIが感情を7カテゴリに分類: 喜び／不安／興奮／警戒／退屈／要求／リラックス
- 推定意図を自然言語で提示（例: 「散歩に行きたがっています。ただし警戒の兆候もあり」）
- 翻訳ログは時系列で記録、週次で傾向グラフを表示

### 2. パーソナリティ診断
- 初回30秒セッションで犬のパーソナリティを16タイプに分類
- 犬種・年齢・既往歴・飼育環境アンケートと組み合わせて、カリキュラムの初期パラメータを決定
- 月次で再診断、成長に応じてカリキュラムが進化

### 3. カスタムカリキュラム
- 16パーソナリティ × 5目的（吠え癖／散歩／トイレ／留守番／社会化）= 80種のベースカリキュラムに、個体差を反映
- 1日5分〜、継続しやすい設計
- 進捗が停滞した場合、AIが自動でカリキュラムを調整

### 4. 音声コーチ
- トレーニング中、飼い主の発声タイミング・トーン・間を解析
- リアルタイムに「今の声かけは犬を緊張させました。半オクターブ低く、ゆっくり話してください」のように指導
- 音声はすべてオンデバイスで処理、録音データはクラウドに送信しない（プライバシー配慮）

### 5. 感情ログ・コミュニティ
- 日々の翻訳ログを蓄積、週次レポートで飼い主にフィードバック
- 同じ犬種・パーソナリティのオーナーコミュニティで知見共有（オプトイン）

## 技術スタック

- クライアント: iOS / Android（React Native）＋ Web（Next.js）
- 感情翻訳エンジン: Gemini 3.1 Flash マルチモーダル + 独自Fine-tune
- 音声コーチ: Whisper-large 日本語＋カスタム発声評価モデル
- バックエンド: Go + gRPC、Cloud Run、BigQuery
- データ: 500万件の犬の行動データ（監修研究所との提携）

## 運用体制

- 獣医師2名 / 動物行動学者3名 / JKC公認トレーナー5名 が監修
- Pro プランでは人間トレーナーへのエスカレーションを24時間以内対応
