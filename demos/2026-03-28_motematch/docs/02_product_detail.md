# MoteMatch プロダクト詳細

## コア機能

### 1. AIモテスコア診断
- 外見・話し方・行動パターン・SNSプロフィールを総合分析
- 0〜100のスコアで可視化
- 弱点3つ・強み3つを具体的に提示
- 診断は無料（週1回更新）

### 2. パーソナライズドコーチング
- 毎朝3分のデイリーミッション（「今日は笑顔を3回増やす」等）
- AIチャットで恋愛相談・シュミレーション
- ファッションアドバイス（写真を送ると採点）
- 会話テンプレート集（1,000以上）

### 3. スマートマッチング
- 相性スコア（価値観・趣味・成長ステージで計算）
- 「成長中の人」同士をマッチング（お互い変わろうとしている人）
- 会話スターターをAIが提案
- デート場所・プランの提案機能

### 4. 成長トラッカー
- 週次でモテスコアの変化をグラフ表示
- バッジシステム（「初デート成功」「連絡先交換」等）
- コミュニティで成功事例をシェア
- 三部・敦史もここで成長を記録中

## 技術スタック
- フロントエンド: React Native（iOS/Android対応）
- バックエンド: Node.js + FastAPI
- AI: GPT-4o + Fine-tuned恋愛コーチモデル
- マッチングアルゴリズム: 独自開発（相性スコア + 成長ステージ）
