# MoteMatch GTM戦略

## ターゲット
**プライマリ**: 20〜35歳の恋愛に自信がない男性
- 「三部タイプ」: 内向的で話しかけるのが苦手
- 「敦史タイプ」: 行動力はあるが空回りしがち

**セカンダリ**: 自己成長に興味があるすべての男性

## 獲得チャネル
1. **TikTok/Reels** - 「三部と敦史のモテ変身ドキュメント」
2. **YouTube** - 「AIにモテ診断してもらった結果...」
3. **X（Twitter）** - モテテクコンテンツ
4. **インフルエンサー** - 恋愛系クリエイター×5名

## ローンチ戦略
- Phase 1（Month 1-2）: ベータ版限定100名（三部・敦史含む）
- Phase 2（Month 3-4）: App Store/Google Play公開
- Phase 3（Month 5-6）: インフルエンサーキャンペーン
- Month 6目標: ユーザー5,000人、MRR 500万円

## 差別化
- 競合（Pairs/with等）はマッチングのみ
- MoteMatchは「変わる過程」をサポート
- 「三部と敦史が変わった」というリアルストーリー
