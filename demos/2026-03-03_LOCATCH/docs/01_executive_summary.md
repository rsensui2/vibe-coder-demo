# 01. エグゼクティブサマリー — LOCATCH

## サービス概要
**LOCATCH（ロキャッチ）** は、自治体が運営する一次産業直売マーケットプラットフォームです。
漁師・農家が水揚げ・収穫物をスマホで即座に出品し、消費者・飲食店・小口卸業者が当日中に購入できる仕組みを提供します。

## 解決する課題
日本では毎年**60万トン以上の未利用魚**が廃棄されています。
- 規格外・小魚：市場で値がつかない
- 獲れすぎ：漁協が受け取れない
- 鮮度問題：従来の流通に時間がかかりすぎる

漁師の手取りは水揚げ額のわずか**30%**。残り70%は仲介手数料として失われています。

## ソリューション
LOCATCHは従来の「漁師→漁協→市場→消費者」という多段階流通を、**3ステップの直接取引**に置き換えます：
1. 漁師がスマホで水揚げ投稿（AI価格提案付き）
2. LOCATCHがリアルタイムマッチング
3. 消費者・飲食店が当日購入・配送

## 自治体にとってのメリット
- 漁業・農業収入UP → **税収増加**
- 地産地消促進 → **観光・移住促進**
- ふるさと納税連携 → **返礼品価値向上**
- Vibe Codingで開発 → **初期費用を従来の1/10以下に抑制**

## ビジネスモデル
- 取引手数料：10%（従来の漁協手数料70%から大幅削減）
- 自治体補助金・地域振興予算を活用した段階的導入
- Phase 1：MVP（0〜50万円）→ Phase 2（〜200万円）→ Phase 3（〜500万円）

## ターゲット市場
- 一次産業が盛んな地方自治体（漁港・農業地帯）
- 全国の市区町村数：約1,700。うち一次産業従事者10%以上の自治体：**約600団体**
