# 02. プロダクト仕様 — LOCATCH

## コア機能

### 1. 水揚げ・収穫投稿機能（漁師・農家向け）
- 写真1枚 + 魚種/作物選択 + 量 + 価格で即座に出品
- **AI価格提案**：市場相場・天気・曜日・過去の売れ行きデータから最適価格を自動算出
- 音声入力対応（スマホ操作が苦手なシニア漁師向け）
- 出品〜マッチングまで平均**3分以内**

### 2. リアルタイムマッチング
- 購入者の位置・嗜好・過去購入履歴からパーソナライズされた通知
- 飲食店向け：前日夜に「明日の水揚げ予報」を配信（仕入れ計画を支援）
- 消費者向け：「いつもの漁師さんが出品しました」プッシュ通知

### 3. 配送・受け取りオプション
- **自治体配送インフラ活用**：既存の地域配送網と連携（コスト削減）
- 直接引き取り（漁港・農地）
- コンビニ受け取り連携（将来拡張）

### 4. 漁師・農家ダッシュボード
- 今月の売上グラフ
- 人気商品ランキング
- 買い手からのレビュー・リクエスト
- 確定申告補助データ出力

### 5. 買い手マーケットプレイス
- 商品検索・フィルタ（魚種・価格・距離・漁師名）
- 生産者ストーリーページ（地域への愛着・信頼感）
- お気に入り漁師登録・定期購入設定

## 技術スタック（Vibe Coding前提）
- **フロントエンド**：Next.js + TailwindCSS（Claude Codeで開発）
- **バックエンド**：Supabase（PostgreSQL + Auth + Storage）
- **AI価格提案**：Claude API（価格最適化プロンプト）
- **通知**：LINE Messaging API（漁師はLINEユーザーが多い）
- **決済**：Stripe（クレジットカード + PayPay連携）
- **地図**：Google Maps API（漁港・農地の位置表示）
