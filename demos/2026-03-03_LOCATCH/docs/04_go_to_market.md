# 04. Go-to-Market戦略 — LOCATCH

## ターゲット市場の優先順位

### Tier 1：漁業特化自治体（先行導入）
- 漁港を持つ市町村（全国約400港）
- 未利用魚問題が深刻な地域（水産庁データベース活用）
- 先進的なDX推進を掲げている自治体

**アプローチ：**
- 水産庁・農林水産省との連携でリスト取得
- 漁業組合・JFへの講演・展示会出展
- パイロット導入：3〜5自治体で実績構築

### Tier 2：農業地帯自治体（横展開）
- 農業産出額が高い都道府県の市町村
- 6次産業化に取り組む農業者が多い地域

### Tier 3：複合型自治体（農業・漁業両方）
- 農業・漁業・林業が混在する地方都市
- 「里の恵み」「海の恵み」を一括プラットフォームで展開

## 導入フロー（自治体向けセールスサイクル）

```
1. 認知形成（1〜3ヶ月）
   展示会・講演・SNS → 担当課への資料送付

2. 提案・評価（2〜4ヶ月）
   デモ環境提供 → 議会承認プロセス支援 → 補助金申請支援

3. パイロット導入（1〜3ヶ月）
   無料or低額でMVP提供 → 実績データ取得

4. 本格契約・拡張（継続）
   成果報告 → 周辺自治体への横展開
```

## マーケティング施策

### デジタル施策
- **SEO**：「自治体 漁業DX」「未利用魚 プラットフォーム」での検索上位獲得
- **YouTube**：導入事例インタビュー動画（漁師の声・自治体担当者の声）
- **X/LinkedIn**：水産業DXトレンドの情報発信

### リアル施策
- **Seafood Expo Asia / Japan International Seafood Show** 出展
- **全国市長会・全国町村会** への提案資料配布
- **水産庁デジタル化シンポジウム** 登壇

### パートナーシップ
- 漁業組合（JF全漁連）との連携
- 地方銀行・信用金庫（自治体向け融資セットで提案）
- 配送会社（ヤマト運輸・佐川の地域配送網活用）
- ふるさと納税プラットフォーム（ふるさとチョイス・さとふる）
