# PriceRadar — Executive Summary

## 一言で
**「もう価格チェックしなくていい。」** チケット・ホテル・航空券のダイナミックプライシングを 24時間自動で監視し、安くなった瞬間にだけ通知するBot嫌い向けの「人間派」価格監視サービス。

## 解決する課題
- ダイナミックプライシングが普及した今、価格は1日に何度も変動する。手動チェックは現実的でない。
- 「気付いたら値上がりしてた」「安いタイミングを逃した」が頻発。
- 既存ツール (Hopper / Camelcamelcamel) は航空券や Amazon に特化。**チケット・ホテル横断・閾値ベース** のサービスは穴。

## ターゲット
1. **米国スポーツ/ライブチケット買付層** (Ticketmaster, StubHub, Vivid Seats)
2. **出張族・旅行者** (Booking, Agoda, APA, Hotels.com)
3. **株価レベルの執着で安値を狙いたい個人** (節約マニア / コレクター)

## プロダクト
| 機能 | 概要 |
|---|---|
| URL監視 | URLを貼るだけで 24h 自動ウォッチ (5–15min ポーリング) |
| 閾値アラート | 「\\$300以下」「20%下落」など条件指定 |
| 履歴グラフ | 過去30日推移を可視化、買い時を判定 |
| 朝イチダイジェスト | 複数アイテムをまとめて1日1回通知 |
| ワンタップ購入導線 | 「今買う？」→ 公式サイトへ。**自動購入はしない (事故防止)** |
