## 収益モデル

### サブスクリプション (主軸)

| プラン | 月額 | 監視数 | 通知頻度 | ターゲット |
|---|---|---|---|---|
| **Free** | \\$0 | 3件 | 60分間隔 | お試し / カジュアル節約家 |
| **Pro** | \\$9.99 | 50件 | 15分間隔 | 旅行者 / チケットマニア |
| **Unlimited** | \\$29.99 | 無制限 | 5分間隔 + AI買い時スコア | コレクター / 法人 |

**14日間無料トライアル / クレカ不要 / 監視3件まで永続無料**

### アフィリエイト (副次)
- 「今買う」ボタン経由の公式サイト遷移で報酬発生
- Booking, Expedia, Hotels.com とは既存パートナープログラム
- Ticketmaster / StubHub は Marketplace API 経由で連携可能性

### 法人 API (M5+)
- 価格監視 API を B2B 提供 (旅行代理店・転売プラットフォーム監視・価格比較サイト)
- 月額 \\$500–\\$5,000 (ボリュームディスカウント)

## 市場規模

### TAM (全体)
- 米国チケット転売市場: **\\$15B/年**
- 米国ホテル業界: **\\$700B/年**
- グローバル航空券市場: **\\$800B/年**
- **TAM 合計: \\$1.5T+**

### SAM (狙う層)
- 米国の月1回以上「価格変動が気になる商品を購入する」層 ≈ **6,000万人**
- そのうち「アプリで管理したい」と考える層 ≈ **1,200万人**
- ARPU \\$60/年 を仮置き → **SAM = \\$720M/年**

### SOM (5年で取りに行く)
- 米国 SAM の 1% = **12万ユーザー**
- ARPU \\$80 (Pro / Unlimited 比率上昇込み) = **年間 \\$9.6M ARR**

## 競合

| 競合 | 領域 | 強み | 弱み |

## Go-to-Market

### Phase 1: コア層獲得 (M1–M3)
- **Reddit (r/sportsbook, r/Ticketmaster, r/travel)** で community-led growth
- Twitter/X で「今日の価格チェック結果」を毎朝投稿 (BOTっぽくなく、人間味で)
- TestFlight / Play Internal で 100名 β

### Phase 2: スケール (M4–M6)
- ASO + Apple Search Ads (\\$50K/月)
- インフルエンサー連携 (旅行系 / スポーツ系 YouTuber)
- Slack コミュニティに無料 Pro 提供 (口コミ拡散)

### Phase 3: B2B 拡大 (M7+)
- 旅行代理店 / 価格比較サイト向け API 営業
- 大手企業の出張部署向け「チームプラン」(\\$199/月 + 上限なし)

## リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| Ticketmaster がクローリングをブロック | 機能低下 | Marketplace API への移行 + 公式パートナー化 |
| Hopper がチケット参入 | 競争激化 | 「人間派」ブランド + コミュニティで差別化 |
| 通知疲れによる解約 | LTV 低下 | ダイジェスト機能で頻度コントロール |
| 法務問題 (転売幇助の指摘) | 風評リスク | 「自動購入禁止」を一貫メッセージング |
